# Spoken-edition declaration v1 (M01)

`reel spoken-edition-validate EDITION` validates strict, bounded JSON using
`reel.spoken-edition.v1`. This is an additive audio-edition declaration, not a
replacement for scene/episode/media or asset schemas. It implements M01 of the
[phased plan](media-expansion-pr-plan.md), following the
[M00 source map](media-expansion-m00.md) and
[fixture specification](media-expansion-spoken-fixture.md).

```sh
cargo run --locked --bin reel -- spoken-edition-validate tests/fixtures/spoken-programme/four-editions.json
cargo test --locked --test spoken_programme
```

## Declaration hierarchy

| Object | Contents and meaning |
| --- | --- |
| Document | Schema, authored ID, 48,000 Hz sample clock; modules, performances and editions |
| Module | Stable module ID, required preceding module IDs and ordered cues; dependency cycles are rejected |
| Cue | Module-local ID, stable speaker-role ID and separately authored language scripts; multiple speakers may occur within a module |
| Script | Cue-local variant ID, language, exact UTF-8 text and SHA-256, plus authority-evidence `FileRef`; two audience adaptations can have different IDs in one language |
| Performance | Module/cue/language/script variant ID and hash, distinct observed-text hash, exact source/alignment references, native duration, word/phrase markers and protected regions |
| Reuse scope | Engineering-signal versus recorded-speech kind, explicit speaker/language, permitted edition IDs and scope-evidence reference |
| Edition | Stable ID, language, audience, required module IDs, ordered module selections and one explicit handoff for every adjacent pair of selected performances |
| Selected take | Performance ID and source interval; all protected words/breaths/tails must remain inside that interval |
| Handoff | Previous/next performance IDs, added pause and explicitly authorized overlap; pause and overlap cannot both be nonzero |

Markers use the existing `CueMarker` structure and word/phrase vocabulary.
Source, alignment and evidence references reuse `scene_delivery::FileRef`.
References in this declaration use bounded relative virtual paths with exact
SHA-256 and byte length. They are not locations to discover or hydrate.
Future native adapters can map admitted asset identities to these scoped names;
M01 does not invent an alternative asset store.

## Checks and limits

Validation rejects unknown/duplicate JSON fields, unsupported schema/sample
rate, duplicate object IDs, invalid hashes, changed script text, unknown cue or
module references, invalid language/speaker/reuse scope, missing or cyclic context
dependencies, wrong cue order/count, missing/extra handoffs, out-of-range markers,
and trims or overlaps crossing protected material.

An edition must select one take per authored module cue, in cue order and the
edition's language. Required modules must precede their consumer. Reuse scope
must name the exact consuming edition; a technical-only scope cannot be reused
by the executive cut. Context closure checks declared requirements, not factual
truth. Protected intervals are half-open sample intervals, as are selected takes.
An explicit overlap must fit both selected spans and touch no protected region.

The JSON input limit is 256 KiB. Limits are 16 modules, 64 total authored cues,
128 performance variants, 8 languages, 16 editions, 8 scripts per cue, 8 KiB per
script, and 1,024 markers/protected regions per performance. Durations and added
pauses are bounded to 720,000 samples each. Each referenced object is at most
16 MiB. These are declaration bounds; aggregate execution/scratch/output budgets
and exact placements remain M02/M03 work, not a successful M01 execution claim.

## Deliberate verification boundary

Validation reads only the requested declaration. It opens no referenced media,
alignment, authority or consent evidence, executes no media/provider process,
performs no network request and writes no report/package or asset record.
The portable `reel.spoken-edition-validation.v1` result contains counts and explicitly reports
`media_verified: false` and `authority_verified: false`. Normal errors use static
diagnostic classes without source paths, scripts, voice identities or raw parser
input. Full source-bearing plans/evidence belong to later private interfaces.

The [public fixture](../tests/fixtures/spoken-programme/four-editions.json) contains
original illustrative EN/ES scripts and six **engineering-signal declarations**.
Its evidence/source pins are synthetic declaration-test values; no corresponding
audio, alignment, consent or authority payload is asserted to exist. M03's actual
media fixtures must bind the generated bytes and measured clocks with real pins.
No observed words are inferred from its scripts or placeholder evidence.

M02 adds sample placements and evidence resolution. M03 adds bounded audio-only
assembly, M04 independently checks media and matching text, and M05 proves
retention/selective invalidation through admitted asset interfaces. Real
language, word-fidelity, naturalness, authority and delivery decisions retain
their separate gates throughout.

Compare two staged revisions of the same declaration after a take selection
changes. The compiler resolves alignment evidence beside each declaration.

```sh
reel spoken-edition-impact previous/edition.json current/edition.json --profile spoken
```

The private report gives exact consumed recipe hashes and one action per
edition. `build` identifies a new edition, `rebuild` a changed recipe and
`removed` an edition absent from the current declaration. `reuse` is eligible
when a prior checked, retained result matches the current recipe and delivery
settings. The report opens alignment metadata and writes no media or selections.
