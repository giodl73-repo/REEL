# Workflow project completion ledger

Objective: finish the workflow project, including new publication types such as
comics. This ledger preserves the full requested scope. A passing native import
or a small comic fixture does not establish project completion. The original
[orchestration plan](workflow-orchestration.md) remains the architecture and
ownership reference. Actual implementation and qualification evidence must be
checked again before closing the objective.

Current ordering: build issue-sized planning/restoration and deterministic worker
dispatch on the bounded native comic receipt/replay path; connect film,
cue/style/language and review/fix flows; implement provider transports; finish
explicit selection/retirement and project adoption qualification. Independent
pieces may proceed in another order when actual evidence makes that useful.
No item is complete merely because its design exists or a narrower fixture passes.

The final audit must inspect every listed command, contract, named integration,
test, gate and deliverable at its actual scope. Unknown, missing or indirect
evidence leaves the objective active. Hosted checks and real service/project
qualification must be reported accurately rather than inferred from local tests.
