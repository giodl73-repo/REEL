# Archived still-presentation worker

The shared `reel-tig-job materialize-presentation PROFILE OUTPUT_DIRECTORY`
worker renders the existing native still-sequence format from a frozen Tig
archive. Invoke it as a step of an explicitly admitted frozen job. The outer
job provides containment, complete workspace/output capacity, source ownership,
runtime enrollment and result retention through the existing shared lifecycle.
This low-level worker does not provide those capabilities independently.
Native execution uses the existing Windows runtime and containment contracts.

The private profile uses schema
`reel.tig-presentation-materialization-profile.experimental-1` and declares the
existing `metadata_root`/`metadata_minimum`, archived `source`, native presentation
`request`, exact `runtime`, `max_primary_objects` and `max_primary_bytes`. It has
no Git/source-checkout input or ambient-program fallback. Object and byte limits
are explicit and checked before primary preparation or output creation. The
existing source compiler retains all approval, source-clock and primary-state
admission checks. A private-source admission remains private-source admission.

The new output directory must have ordinary existing parents outside metadata
and asset object stores. Existing directories, traversal and reparse parents
refuse. Output names and media semantics come from the existing still renderer:
`master.mkv`, `review.mp4`, `receipt.json` and renderer-owned editable-layer/font
copies. `native-source.json` additionally binds the exact profile, source
checkpoint, root and compiled manifest. Retain the declared results through the
outer job; no source or delivered selection changes automatically.

Primary and exact-program guards stay live through native rendering and the
complete shared checker. Successful materialization is an unapproved candidate,
with production-current, original-producer, complete-environment/semantic,
adoption and eviction claims all false. Episode integration still requires the
normal fresh component reference and final conform checks, actual review and
the relevant human approval. Do not relabel a materialization receipt as any of
those later gates.

Producer review: rights/provenance preserves archived sources and exact scoped
admissions; platform/audience retains the native clean master and separate
review derivative without claiming phone, listening or human acceptance.
