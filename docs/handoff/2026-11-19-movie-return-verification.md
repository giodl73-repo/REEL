# Independent returned-movie verification

`movie::check_returned` checks externally supplied or relocated movie candidates
against the exact FilmRender task and live original input authority. It verifies
the result/attempt, complete portable return mapping/inventory, every artifact
hash/length, the canonical task-bound worker receipt and producer request/outcome
correspondence. Evidence's historical machine locators are checked as declarations;
they are never opened to substitute for current admitted inputs.

The parent holds current native input/program guards and exact supplied output
file/namespace guards throughout a separate contained `Verify` child. Its runtime
is explicitly pinned independently of the historical producer executable. The
child uses the existing renderer's full media checker, then compares the master's
decoded YUV, RGB and PCM streams with existing primary picture/mixer reconstruction.
It writes no replacement movie. Compiled controls, counts, outputs and execution
limits still come from the exact task; verification cannot shorten an edition.

Virtual renderer output names map to actual guarded files, allowing scattered
returns without restoring the producer's original directory layout. Caller-owned
verification scratch must be empty, separately capacity-admitted and disjoint from
the returned files, source checkout, native pool and custody metadata. Existing
128 MiB ingress and bounded process/workspace limits remain. The child records
a bounded request-bound outcome; uncertainty preserves scratch and refuses a
replacement launch. Read-only verification replay/reconciliation remains work.

`Checked` retains actual input and returned-file guards. It is not a retained-owner
acknowledgement, task completion, selection, creative approval or authority to
delete scratch. Automatic movie dispatch and candidate ingress remain gated until
this check is connected with native retained-output/history verification and the
original managed lifecycle. The existing media checker/review-map checks are not
an exhaustive adversarial OCR or pixel verification of review labels.

The synthetic fixture reuses the original movie admission, prepares separate owned
verification capacity, and relocates outputs under opaque `.bin` names. It checks
positive verification, write refusal while guards live, pre-child hash-corruption
refusal and a repinned alternative film whose plan/map/hashes are made consistent
with the original task. The primary comparison must refuse the wrong picture.
Actual qualification evidence will be recorded after execution.

Producer-applied editor and rights/provenance review: current source pins and
primary clocks determine the comparison; supplied producer assertions cannot
authorize different media. Private machine evidence remains private. Technical
verification does not grant translation, voice/font, creative, publication or
release approval. This is a checklist application, not independent human review.
