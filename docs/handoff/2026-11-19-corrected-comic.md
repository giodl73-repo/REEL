# Corrected comic production from a retained finding

The native qualification fixture `repair_comic_native` connects the existing
repair compiler to actual comic production. It consumes an existing retained
synthetic comic and its retained structured-review report, verifies their exact
publication/commit/project correspondence, and reads the original committed
inputs through the native reader. The original source may be bare history and
its original actor slot may already have been reused.

The authored synthetic correction changes one Spanish balloon from
`La luz sigue.` to `Mira la luz.`. It updates the page-source descriptor in both
the build request and publication master. Those three explicit before/after
edits become a candidate plan at a new committed snapshot with a fresh native
declaration. This fixture supplies authored replacement bytes; it does not ask
an LLM to decide wording or infer an approval.

The plan then enters a fresh bounded job in the existing synthetic pool:
accept durable input protection, publish the three corrected input objects,
create its original handoff, stage exact inputs and run the owned comic worker.
The producer retains its original qualified runtime choice. New control code
does not retarget that runtime or modify the old job. Standard dispatch handles
result ingestion, retained-owner acknowledgement and journal completion, then
replays the completed operation.

Checks reopen the retained outputs, compare clean-art bytes with the old
publication, require changed reading pixels and corrected transcript text, and
export a full corrected-edition review copy under retained producer proof.
Page/panel/utterance unit identities remain stable. The review media and source
commit change, so the old review report must refuse against the new copy.
Claims belonging to the original comic and original report must remain unchanged.

`CheckedReport` is now clonable as an owned semantic assessment. This supports
keeping its exact finding/repair contract after dropping native read guards
before another lifecycle operation. A cloned assessment carries no native
guard, custody, retained ownership, completion permission or approval.

## Scope

This is a bounded one-page Spanish comic edition using previously qualified
synthetic media and its existing installed-font scope. It does not qualify a
larger complete issue, film repair, bilingual correction, model-generated fix,
tracker adoption or automated issue closure. Producing a new contextual review
copy does not prove that a reviewer inspected it. Actual contextual/creative
review, selection, print approval and release remain separate requirements.

The fixture preserves new and historical roots, the original operation marker,
phase observations, source commit, packet, receipt, handoff profile, worker
tickets/results and acknowledgement. Failure must be recovered from those exact
handles; never rerun the entire fixture under a new identity after effects.

Applied the editor, comics-editor and rights/provenance checklists: the corrected
wording is explicit synthetic input, neighboring/full-edition review remains
required, editable source pins survive, and technical completion grants no
canon, translation, font or public-release authority.
