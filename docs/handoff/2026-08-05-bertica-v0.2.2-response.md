# REEL response to BERTICA v0.2.2

REEL CLI v0.2.2 uses frame-evaluated FFmpeg perspective sampling with cubic
interpolation. Unlike delivery-resolution `zoompan`, the perspective backend
samples fractional source coordinates on every frame. Cosine ease-in/out is the
default. Current `reel.manifest.v0.2` files need no migration and no portable
motion field was added.

## BERTICA consumption commands

Rerender one short proof to a new filename first:

```text
reel animatic-render production/reel/conformed/scene-v2/manifest.yaml --asset-root C:/src/bertica --audio production/audio/master.wav --captions production/reel/conformed/scene-v2/captions.srt --output production/video/scene-v2-smooth-v022.mp4 --motion-quality smooth --motion-curve ease-in-out --format json
reel motion-analyze production/video/scene-v2-smooth-v022.mp4 --output json
```

Reproduce the old renderer without touching the old file:

```text
reel animatic-render production/reel/conformed/scene-v2/manifest.yaml --asset-root C:/src/bertica --audio production/audio/master.wav --captions production/reel/conformed/scene-v2/captions.srt --output production/video/scene-v2-legacy-v021-rerender.mp4 --motion-quality legacy --format json
```

REEL will refuse an output path that already exists. Keep the existing BERTICA
v2 files until the smooth candidates receive human approval. Rendering changes
motion sampling only; it does not change voice choice, cue timing, captions,
source references, visual assets, or review state.

## Acceptance evidence

The published metric counts adjacent decoded-frame differences with average
absolute luma below 0.001 as near-stationary. Moving shots pass at or below 10
percent.

- sanitized 20-second pan: legacy 333/479 (69.52%, fail), smooth 4/479
  (0.84%, pass);
- sanitized 25-second push: 33/599 (5.51%, pass);
- sanitized 25-second pull: 33/599 (5.51%, pass);
- `hold` and `hold-dark` bypass perspective and retain static position;
- CFR, duration, captions, disclosure, silent/audio paths, crop bounds, and
  artifact lineage remain under production CLI tests.

A sanitized 10-second side-by-side proof is generated from
`manifests/fixtures/smooth-motion/`; it contains no BERTICA manuscript, photo,
voice, or private render.

## Performance and retained records

On WSL2 / FFmpeg 6.1.1, the 20-second fixture rendered in 6.53 seconds with 540
MiB maximum RSS at 1280x720, and 7.12 seconds with 1,309 MiB at 1920x1080.
v0.2.2 bounds rendering at 1080p pixel count and 60 fps; infeasible requests
fail before output creation.

Retain each `*.artifacts.json`, especially `tool_version`, `ffmpeg_version`,
the complete `motion` object, `inputs`, `command_arguments`,
`output_sha256`, `output_bytes`, and `output_duration_ms`. The motion object
contains backend/version, quality, interpolation, curve, sampling strategy,
working resolution, fps, resource limits/estimate, quality override, and
per-shot treatment/frame counts.
