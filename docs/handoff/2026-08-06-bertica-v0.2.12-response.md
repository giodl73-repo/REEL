# BERTICA v0.2.12 response

The requested P1 controlled comparison derivative is implemented separately
from scene canon. BERTICA should create `reel.comparison.v0.1` YAML referencing
each candidate video, privacy-safe animatic receipt, and local artifact report,
then run:

```powershell
reel comparison-compose path/to/comparison.yaml `
  --output path/to/review.mp4 --format json
reel comparison-receipt-check path/to/review.comparison.receipt.json `
  path/to/review.mp4 --output json
```

The composer verifies children, requires distinct receipts/videos, compares all
declared fixed dimensions from available evidence, and proves the allowed
dimension actually changes. It supports a neutral opening slate, per-variant
slates, local chime with protected silence, optional replay, descriptive labels,
and deterministic seeded A/B/C labels.

Keep the YAML and `*.comparison.artifacts.json` private: they preserve the raw
seed, child IDs, decode map, embedded child receipts, and local lineage. The
`*.comparison.receipt.json` is the intentional path-free shareable derivative;
it omits IDs/labels/decode/instructions and never calls inclusion or order an
approval.

Acceptance composes three generated six-second caption variants while holding
motion, audio, visuals, duration, and streams fixed, then rejects a fourth
independently valid child with a changed audio hash before publication. No
BERTICA media is used. Existing BERTICA manifests require no migration and
`reel.manifest.v0.2` is unchanged.
