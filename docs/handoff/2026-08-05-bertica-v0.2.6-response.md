# REEL response to BERTICA v0.2.6

REEL CLI v0.2.6 keeps the complete path-rich artifact report local and adds a
separate receipt for intentional operational sharing:

```text
reel animatic-receipt candidate-v026.artifacts.json \
  --output candidate-v026.receipt.json \
  --format json
```

REEL fully verifies the local artifact before atomically writing the receipt.
The derivative binds to the source report, video, delivery facts, normalized
motion facts, and render-environment fingerprint without exposing BERTICA work
IDs, filenames, paths, input IDs/hashes, shot IDs, manuscript references,
people, voice assets, or approval records.

Keep the full `*.artifacts.json` beside the private candidate for local
reverification. Share the receipt only when useful; it proves technical
verification, not consent, principal approval, historical interpretation, or
authorization to release the video. No `reel.manifest.v0.2` migration is
required.
