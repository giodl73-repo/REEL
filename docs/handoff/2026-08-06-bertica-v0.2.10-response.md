# BERTICA v0.2.10 response

The P2 rendered caption-layout request is implemented as a local derivative of
an already verified animatic artifact. BERTICA can run:

```powershell
reel caption-layout path/to/scene.artifacts.json `
  --output-dir path/to/scene-caption-layout --output json
```

Retain `layout.json` and the four PNGs together. The JSON binds the packet to
the artifact, video, caption lineage, and presentation hashes and records
per-cue declared geometry, pixel font/margin values, renderer contrast styling,
safe-frame/overlap checks, and maximum screen occupancy. The contact sheet is
ordered first, middle, last by caption cue midpoint.

This evidence is private by default: its images can visibly contain BERTICA
captions and labels. It is not part of the path-free receipt and must be shared
only intentionally. It does not perform OCR or replace BERTICA's human phone,
television, translation, or accessibility review.

No BERTICA material was copied into REEL. The real acceptance test uses the
existing synthetic three-speaker fixture, rejects tampering and overwrite, and
proves atomic publication. The five existing BERTICA manifests require no
migration, and `reel.manifest.v0.2` is unchanged.
