# BERTICA v0.2.7 response

REEL now lets a recipient validate the intentionally shared video using the
path-free v0.2.6 receipt, without disclosing BERTICA's private artifact report:

```text
reel animatic-receipt-check candidate-v027.receipt.json \
  candidate-v027.mp4 --output json
```

The receipt is decoded strictly, the video is hashed and probed, and the result
is a second path-free report. The check covers video identity, byte length,
H.264/yuv420p delivery, dimensions, CFR, duration, and audio-stream state.

This provides integrity evidence only. It is not a signature and does not prove
authorship, consent, approval, release, caption wording, or the private source
artifact without that artifact report.

`reel.manifest.v0.2` is unchanged. No manifest migration is required.
