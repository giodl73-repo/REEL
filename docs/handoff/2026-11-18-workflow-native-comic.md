# Native comic workflow — producer handoff

The workflow now accepts deterministic comic results through the same native
registration/retention/journal path as provider results. An optional v2 result
`worker_receipt` pin preserves older provider serialization when absent; native
comic import requires it. The actual receipt object is logically registered,
published and retained with the outputs. Forged approval/retention/print claims
remain refused. Supplied worker provenance is not an authenticated execution.

The publication producer now exposes a bounded injected-reader replay seam over
its existing renderer. Native verification reads the exact selected Git records,
annex leaves and source bytes, checks edition/language/page/panel/utterance/source
correspondence and rerenders the complete expected packet. Every output and
captured editable source copy must match; unexpected files and reparses refuse.
The same native executable offers `comic-render` and `comic-check` with the same
locked renderer dependencies, so it can produce the bytes its verifier expects.
Standalone worker success is not native task completion.

Retained comic proof requires original native source payloads and output objects,
then repeats deterministic replay without the worker's original input folder.
Missing historical bytes stop; latest/current substitution is not allowed. The
synthetic fixture switches its repository locator to bare history and removes
the original worker input directory before successful retained journal resume.
Native editable packet export/restore is still separate work.

Native object gates are exclusive. One operation now reuses a held read per
physical object after exact logical record/leaf verification, and duplicate
output bytes publish/reopen once while all logical artifact identities remain
in immutable registration. Comic proof owns its source/output guards rather
than opening the same native objects twice. This is ephemeral guarded-read reuse,
not another cache. Read handles close for index admission and reopen afterward.

The result contract permits up to 256 artifact descriptors, with 128 MiB total
returned payload including receipt; original renderer/input/resource limits apply.
Actual native changes must still fit 128 paths, and a successful job's final flat
source reference tree must remain within the qualified 128-path close phase.
An oversized output set refuses before new protection or publication, preserving
the original closable input job. Larger issues require explicit page/part plans;
raising the descriptor ceiling does not implement that planner or bypass Tig.

Evidence includes forged-approval and altered-render refusal, duplicate physical
output bytes under distinct logical IDs, source-close budget refusal, full native
comic completion and historical replay. Shared bilingual comic/source-restoration,
font/raster/PDF and workflow contract regressions also apply. Vendored SDK and
lifecycle sources remain exact; the isolated Cargo lock adds the shared renderer
dependency graph and is requalified as part of this native executable. No existing
producer SDK, selected project profile or project asset was changed.

Validation: 49 shared workflow/publication/print tests, 34 default native tests and
six explicitly invoked native fixtures pass (89 distinct tests). Both locked
dependency graphs pass strict Clippy and formatting checks locally; original
247 SDK and two lifecycle module/test source pins remain exact. Hosted CI has
not run. Synthetic evidence, committed-source manifests and frozen paired native
worker/verifier tools are kept outside Git. The duplicate-output fixture also
passed a retained-owner/readback check for its two logical roles.

The [completion ledger](../workflow-completion.md) keeps the full goal active:
issue-sized partition/assembly and dispatch, native restoration, film/cue/style/
language integration, providers including speech, review/issue/fix flow, explicit
selection and guarded retirement remain required. These synthetic fixtures do
not adopt BBJ/Melena or grant creative, translation, font, likeness/voice, printer
or public release approval.
