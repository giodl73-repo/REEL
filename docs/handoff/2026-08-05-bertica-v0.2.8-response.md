# BERTICA v0.2.8 response

Before rendering a conformed BERTICA packet, run:

```text
reel caption-check production/conformed/scene-v2/captions.srt --output json
```

REEL checks strict SRT structure, display duration, characters per line, lines
per cue, and reading speed. A failure returns every affected cue index without
printing manuscript or caption text. BERTICA may override the four thresholds
when a documented Spanish-language or platform policy requires it; the chosen
values remain visible in the report.

This audit covers the SRT, not the burned pixels. Continue using
`animatic-check` to bind the caption file to its render and human platform review
to judge safe area, contrast, size, line breaks, translation, and phone
legibility.

`reel.manifest.v0.2` is unchanged. Existing BERTICA manifests require no
migration.
