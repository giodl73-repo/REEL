# Verified run frontier and protected manual batches

The pure workflow graph now distinguishes unadmitted tasks, verified Waiting jobs,
pending imports, retained observations, cancellation, blocked dependencies and
refusals. Actual verified parent results determine child dependency fingerprints;
local retained markers cannot unlock children alone. Refused branches do not hide
independent work. Errors are bounded/sanitized, and inspection omits prompts.

Native run bindings name existing journals, pinned profile controls and optional
pinned staging tickets. Inspection checks original runtime bytes without
impersonating that runtime for effects. It reopens actual claims or retained
proof. Observations are sequential and are not a new atomic custody certificate.

Explicit ready export supports at most 16 selected admitted Waiting jobs. It holds
original journal controls, reuses existing owned staging and conservative capacity,
reads actual native inputs, and rechecks claims before publishing a private batch.
The batch includes original tickets, attempts, runtime pins, packets/prompts and
input-binding paths. It does not invoke providers or deterministic workers. Return
checks the batch and current plan/frontier before delegating to original lifecycle
import/recovery. Pending/retained replay must match the original result body.

Protocol fixtures pass for dependency gating, stale child attempts, independent
branches, interrupted/cancelled jobs and privacy-safe errors. The native missing
payload case refuses export despite valid claims/local controls. An explicitly
enrolled two-slot fixture stages both jobs against one retained target and shared
acknowledgement directory without a duplicate writer lock. The existing-store
return/recovery fixture passed after its initial run caught a missing explicit
false scratch-retirement flag in the new CLI result. It verifies the batch round
trip, changed-plan refusal, original native Prepare reconciliation, downstream
frontier continuation and corrupt-acknowledgement blocking.

Validation: 60 shared tests and 36 default native tests pass. Seven existing-store
cases passed in the full native run; the eighth ready-return case passed when
rerun after that response-only correction (104 distinct tests). The unrelated
seven were not repeated for the JSON flag correction. Both dependency graphs
pass strict Clippy; two test-only slice-clone warnings were corrected. Formatting
and diff checks pass. Initial failure logs are preserved alongside passing
targeted evidence. Hosted CI has not run. Frozen original/corrected tools,
synthetic controls and source manifests remain outside Git.

The bytes of current task inputs still come from exact committed native declarations.
Dependency result references do not forward unselected parent payloads into those
declarations. Full retained upstream inputs, comic assembly, automatic worker/API
execution, slot admission/close scheduling, selection and scratch/capacity retirement
remain open in the [completion ledger](../workflow-completion.md). Source, actor,
changed-path, byte and namespace limits remain unchanged. This does not adopt
project assets, alter selected records or grant creative/rights/print/release approval.
