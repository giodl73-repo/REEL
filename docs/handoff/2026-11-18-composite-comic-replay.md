# Composite comic production and retained replay

Comic source binding now accepts an input reader authorized by actual job claims
or verified retained coverage. The exact source declaration and input selection
must match the sealed permit. Saved profiles, origin maps and acknowledgement
JSON cannot construct a permit. It keeps shared ownership of the actual actor
fences; nested checks do not reacquire the same writer fence. The small permit
handle preserves the prior Windows stack-layout fix.

Worker preparation and generation consume original child job guards. Returned
comic files are fully replayed from admitted inputs before publication effects.
Retained verification, parent-result reads and editable export obtain permits
only after validating original retained work and coverage. These checks can
reopen composite inputs after the original source actor's coverage is gone.
Native object gates remain scoped to reads and drop before index mutations.

The fixture models a PNG candidate parent, exact retained-result binding, mixed
Git/upstream comic admission, graph parent verification, protected ready export,
in-process production, returned-file refusal/recovery and retained completion.
It then removes original job coverage only in the synthetic test index and checks
bare-history replay, native editable export, restoration and a fresh text edit.
This does not qualify production actor close/release, complete issue assembly,
external providers or creative/translation/font/print/release approval.

Producer-applied comics, story/editorial, platform/audience and rights/provenance
checks preserve declared master, part, page, panel, utterance and language
identities. The retained image's logical origin is checked before physical byte
reuse. Source controls remain private and no provider calls are implicit.
