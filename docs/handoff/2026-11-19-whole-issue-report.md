# Protected whole-issue structured review

`review::comic_reading_inputs` now verifies the exact selected manifest byte pin,
schema, language, edition metadata and page order, then returns the PNG artifact
pins in reading order. Missing/extra pages, repeated logical image identities,
non-PNG material and changed manifest bytes refuse. It reads no images and grants
no native custody or viewing authority. Existing review request/copy schemas and
legacy review interpretation remain unchanged; text-only review remains possible.

The native qualifier consumes the already retained whole-issue control task and
both original part results. Its six declared inputs are the exact publication,
three retained control outputs and two original reading PNGs. The image selectors
come from the exact original part results captured by the control producer;
opaque editable carriers and fonts are not sent as viewing material. Full parent
custody and producer replay remain native admission obligations.

Before any close, the fixture validates its complete native projection. It then
uses the completed control task's original frozen runtime/profile to close that
job into retained coverage, and explicitly reuses enrolled slot2 for a distinct
report task/attempt. The new task pins a newly built optimized runtime; no old
job runtime is adopted. The other protected Waiting generation stays unchanged.

The fixture independently admits/protects the six inputs, prepares an owned
staging ticket, exports the actual six-unit review brief with both image pins,
and verifies native PNG reads. Scripted reports with a stale copy, unknown page
unit or changed evidence pin must refuse with their specific structured errors
before import intent, leaving the actual Index checkpoint and Waiting journal
unchanged. The valid scripted technical report targets balloons on both pages,
uses the original attempt and exact pretty-printed bytes, reaches retained-owner
acknowledgement and durable completion, replays without return-file arguments,
and reopens a native checked report. Original small controls must retain their
byte pins and the other Waiting job must reopen. Qualification is pending.

This is a scripted technical protocol exercise with no actual model call or
creative defect assertion. Declared/staged images and a valid report are not
verified viewing. Native report retention, actual image inspection, creative
review, issue delivery, repair execution, source selection and release remain
separate. There is no tracker/network call, selected master, runtime adoption,
scratch retirement or payload deletion. Preserve every partial original
operation, activation, WorkRef and workspace; never restart the whole fixture
under a new identity after uncertain effects.

The producer checklist follows `.roles/ROLE.md`, comics/editor and
rights/provenance: whole-edition page order and original target identity must
survive, exact language/source wording stays fixed, and no model/human approval,
translation, font authority, print readiness or publication is inferred.
