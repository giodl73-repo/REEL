# BERTICA v0.2.11 response

The requested P1 audio gate and optional artifact binding are implemented. For
a private master, BERTICA should retain a path-free report and bind it to the
candidate render:

```powershell
reel audio-check path/to/master.wav --profile private-review `
  --manifest path/to/manifest.yaml --report path/to/master.audio-check.json `
  --output json

reel animatic-render path/to/manifest.yaml --asset-root path/to/assets `
  --audio path/to/master.wav `
  --audio-check-report path/to/master.audio-check.json `
  --captions path/to/captions.srt --output path/to/candidate.mp4
```

The report includes loudness, true/sample peak evidence, stream facts, silence
ranges, duration, hashes, and optional narration/effects margin without paths,
names, or prose. A failed profile or duration mismatch blocks the report/render;
audio tampering invalidates binding before output publication.

The analyzer is local and read-only. It does not normalize, upload, clone,
synthesize, select, or approve BERTICA voices. No private BERTICA audio was
copied: acceptance WAVs are generated synthetic sine signals inside temporary
test directories. Existing manifests require no migration and
`reel.manifest.v0.2` is unchanged.
