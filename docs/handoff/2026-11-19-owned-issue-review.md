# Owned whole-issue review controls

`review_control::bindings` now constructs the explicit review-task upstream
declaration from the producer's exact original upstream control and its returned
outputs/worker receipt. It verifies the inherited control's byte pin, declared
original parent set and input names, rejects missing/extra controls or origin
aliases, and preserves existing upstream version/budget semantics. With a fixed
source producer it emits upstream v2. This is planning metadata; the native
adapter must still verify all retained parent results and original custody.

This closes an important issue-consumer planning gap: the assembly's part
receipts, editable carriers and derived assembly request remain tied to their
original producers. A new consumer cannot copy the assembly source profile and
treat its inherited inputs as undeclared fixed records. The child declares the
root issue plus those exact ancestors, with its own native snapshot and claims.
