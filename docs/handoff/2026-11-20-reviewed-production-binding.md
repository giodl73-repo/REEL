# Producer-bound reviews across task snapshots

A repaired issue can combine an opening at source B, a historical closing at A
and assembly at C. A shared publication pin and one language do not identify
which producer a report reviewed. Legacy scoped-plan repair inspection therefore
continues refusing ambiguous commit sets.

New comic review controls explicitly opt into a bound request through
`review_control::bound_source_bindings`. This adds the actual producer receipt at
the reserved `production/receipt.json` source path. Without that authored entry,
the existing generator still emits the exact v1 request bytes. With it, the
generator emits `reel.workflow-review-request.v2`, including the exact producer
packet and returned result. V1 forbids the witness; v2 requires it. A malformed
source marker refuses rather than silently changing protocol.

`review::bind` checks the witness against the copy's project, exact source,
language, publication, format and deterministic tool/receipt. A checked report
retains the witness privately. Repair planning reconstructs the reviewed packet
against the supplied plan, including its original dependencies, rather than
guessing from every task that references the same master. Changed reviewed task
contracts refuse even at the same commit; unrelated task changes are permitted.
Resolution also checks an available bound witness against the named corrected
production task. This does not infer resolution from an empty report.

Descriptors alone are planning evidence. The native v2 path additionally requires
actual admitted origins for request, copy and source manifest from one retained
comic review-control task. That task must reference the exact producer receipt,
inputs and dependency result; the canonical request pin must match that chain.
A source-authored witness, another attempt or matching bytes under another
selector cannot stand in for it. Live claim/retained permits remain necessary;
no new cache, source lookup fallback, provider authority or byte custody follows
from a witness. Native v2 film control generation is not qualified by this comic
adapter; existing film/v1 protocols remain unchanged.

Three synthetic contract tests cover mixed snapshots, original v1 bytes,
required/versioned witnesses, changed producer contracts, wrong result attempts,
source-authored request origins and incorrect selectors. They also preserve the
exact producer when unrelated tasks change. The complete workflow suite passes
(146 tests); strict workflow and film-native Clippy pass.

An opt-in read-only native preflight consumes the certified retained corrected
issue, borrows original native lineage and replays the complete producer using
the same callback as production. It will emit prospective v2 controls and a
two-page/six-unit context request, with both reading images declared, while
checking the actual Index remains unchanged. It does not close the issue's slot,
admit the new task, retain controls or a report, call a provider, assert viewing,
close a finding, select or approve anything. This preflight has not yet run.

Producer-applied comics-editor and rights/provenance checklists require exact
whole-issue context and immutable lineage while keeping technical inspection
separate from editorial authority. They are not independent or human reviews.
