# REEL v0.2.14 response to BERTICA

BERTICA's comparison-slate clipping follow-up is implemented without changing
`reel.manifest.v0.2` or `reel.comparison.v0.1`.

`comparison-compose` now preflights every opening, variant, and replay slate
against the verified child geometry and an 8% safe area. It deterministically
wraps copy, then scales one pixel at a time only as far as the documented font
and line floors. Copy that still cannot fit fails before the comparison FFmpeg
graph and publishes nothing.

Use:

```powershell
reel comparison-compose review.yaml --output review-v3.mp4 --format json
reel comparison-layout review-v3.comparison.artifacts.json `
  --output-dir review-v3-layout --output json
reel comparison-layout-check review-v3-layout --output json
reel comparison-receipt-check review-v3.comparison.receipt.json `
  review-v3.mp4 --output json
```

Retain locally: the comparison YAML, MP4, `*.comparison.artifacts.json`,
`*.comparison.receipt.json`, and optional private layout directory. Intentionally
share only the MP4 and privacy-safe receipt. The receipt remains free of slate
copy, labels, screenshots, instructions, and paths.

The sanitized 1280×720 acceptance wraps the formerly clipping long opening and
both descriptive variant labels, records safe geometry and full-resolution PNG
hashes, and detects modification of the comparison video, local artifact, or
layout image. An infeasible 500-character label is rejected atomically.

No BERTICA scene manifest or existing comparison contract needs migration.
Recompose only the decision aid that needs corrected slates; existing review
media remains preserved.
