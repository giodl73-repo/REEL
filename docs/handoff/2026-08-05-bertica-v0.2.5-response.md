# REEL response to BERTICA v0.2.5

REEL CLI v0.2.5 embeds the successful render-environment preflight inside each
real sibling `*.artifacts.json` report. The report now carries the WSL/native
transport, FFmpeg and ffprobe identities, all seven required capabilities, and
a deterministic SHA-256 fingerprint.

BERTICA should continue to render to a new candidate filename, then run:

```text
reel animatic-check candidate-v025.artifacts.json --output json
```

The verifier rejects v0.2.5+ evidence if the environment object is missing,
incomplete, failed, reordered, fingerprint-inconsistent, or disconnected from
the recorded FFmpeg motion backend. Keep the candidate video and its sibling
artifact report together.

No `reel.manifest.v0.2` migration is required. Source timing, captions, voice
choice, visual content, private paths, and review status do not change.
