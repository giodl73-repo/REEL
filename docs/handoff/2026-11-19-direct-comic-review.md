# Native direct structured comic review

The [Responses text/review adapter](2026-11-19-openai-text-adapter.md) has two
native qualification fixtures for a protected `review-report` task. They reuse
the exact previously retained synthetic comic input records and bytes, clone the
consumer snapshot as bare Git and admit their own job contexts. They neither
rewrite the production commit nor republish inputs or retarget the prior job.
The source and consumer commit identities remain separate.

The local scripted service checks the exact copy fingerprint in the strict wire
schema, Spanish language, production commit, balloon unit key, report name and
inline PNG hash/length. It returns a nonempty report with an explicit Text finding,
Project route and an existing allowed image evidence descriptor. This checks
transport and semantic contracts; it does not claim a model or person inspected
the artwork.

The positive case checks six-output retained completion, moves only its owned
local return packet aside, and verifies the report with live retained proof from
native bytes and bare Git. The historical proof must contain the finding. Its
replay must use retained completion without another HTTP request or claim change.

The negative case supplies the correct copy fingerprint and valid report
structure but an invented unit ID. The existing native contextual validator must
refuse it before `ImportPending` or candidate registration. Its original job
stays Waiting, its journal stays byte-identical, claims remain unchanged and no
retained acknowledgement is created. Complete response/candidate-envelope files
remain private evidence; their existence is not native candidate registration.
Replay rechecks the original completed response and must not make another call.
This response is a semantic failure, not a missing or truncated transport reply.

Both fixtures compare the prior retained job's claims before and after execution.
Each saves original operation controls before admission and preserves all roots.
Moving the positive fixture's owned return directory uses checked canonical
paths under its original root; this is no scratch retirement or deletion.

Applied comics-editor and rights/provenance checklists: balloon/page identity,
unchanged Spanish source, exact immutable evidence, contextual findings and
private egress stay explicit. A valid report grants no canon, translation, image,
font, candidate selection, print or release approval. Whole-issue neighboring-page
review, film/audio review and actual model/project qualification need their own
evidence.

## Original-operation qualification recovery

The initial positive fixture reached Retained, moved local returns aside, passed
native historical proof and obtained a successful already-ready replay. Its final
socket probe then blocked in the harness. An empty connection to that original
synthetic listener released the wait and exposed the assertion failure. This
connection was a diagnostic probe after workflow child exit, not another provider
HTTP request. The failed fixture/log and original protected root remain intact.

The harness now explicitly sets the cloned observer nonblocking. A separate
recovery test reopens the original packet/source/admission/receipt/result/ack,
checks native history with local returns absent, and replays with the original
pinned executable. It neither starts the positive fixture fresh nor readmits or
republishes inputs. The initial prior-claims comparison was after the failed
probe and was not reached; recovery can only compare those claims across the
resume itself. This limit must remain visible in the qualification evidence.
