Second bounded port from PR #89: source-bound alpha/ASS layer expectations,
visibility and frame-indexed motion checks, ordered timed overlays followed by
one final full-scene ASS presentation, and retained-picture-frame ASS bounds.
Ports `6e231be`, `c554737`, `b674148`, `79c3791`, `4cf852f`, `6dc79fa`,
`808992f`, `2665d80`, `aaee24c` onto the native-motion integration.

Preserves current main's repeat-last, explicitly bounded overlay end-frame fix
and its unified `still_sequence_encoding` compositor behavior. The older
`cae364c` encoding capability is already covered by that current API; no parallel
`composition_encoding` option is restored. Both compact-codec and persistent
text assertions remain. The project-specific private-poem test stays archived;
the public regressions use synthetic sources and retained-frame text states.

Existing semantic picture transforms remain supported. Combining those
transforms with a final ASS layer requires explicit composition migration;
the old implementation did not support that combination either. Post-compose
camera analysis remains explicitly unsupported by the layer validator.

Producer-applied animation/editor/sound/provenance review: source motion is
distinct from surviving visible contribution; hidden or insufficient evidence
is inconclusive, not a pass. Wrong ordering, changed sources and wrong native
intervals reject. No private project qualification or creative approval is
inferred from the generic synthetic regressions.
