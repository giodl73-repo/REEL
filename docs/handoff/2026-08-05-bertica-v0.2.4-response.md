# REEL response to BERTICA v0.2.4

REEL CLI v0.2.4 adds an executable render-environment handoff while retaining
`reel.manifest.v0.2` unchanged. Before the first rerender, run:

```text
reel render-doctor --output json > production/reel/evidence/render-environment-v024.json
```

The command verifies FFmpeg and ffprobe version identity, `drawtext`,
`subtitles`, `perspective`, `framerate`, and `xfade`, cubic perspective
interpolation, and `libx264`. It uses WSL on Windows and native executables on
Linux, matching REEL's actual render adapter.

`animatic-render` enforces the same gate before starting a real render. Missing
capabilities are named precisely and cannot leave a partial video or artifact
report. BERTICA's manifests, source timing, private assets, voice choices,
captions, and review state require no migration.
