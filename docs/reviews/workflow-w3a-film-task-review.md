# W3a film task, retained candidate and recovery review

Author-applied [.roles](../../.roles/ROLE.md) checklists, not independent review
or creative approval. Scope is a bounded Rust adapter; owned CLI dispatch and
project adoption remain later gates.

| Lens | Finding and disposition |
| --- | --- |
| [Editor](../../.roles/editor.md) | Bind exact compiled job/production controls and authored aliases, then compare the full producer output set before execution. Retain story/cel/cue clocks and IDs from those controls. Recovery checks original media rather than producing another cut. |
| [Rights/provenance](../../.roles/rights-provenance-steward.md) | Arbitrary tool-result JSON remains refused. Only actual task-bound production constructs the guarded candidate. Retain its exact worker receipt alongside media; write technical completion only after native retained coverage and byte reopen. No creative approval, voice authority or selection is inferred. |
| [Rights/provenance](../../.roles/rights-provenance-steward.md) | Freeze task/attempt, admission generation, source, programs and workspace identity before dispatch. Reconcile original native registration/retention work on uncertainty. Another workspace or result conflicts; missing history never falls back to latest. |
| [Platform](../../.roles/platform-audience.md) | Reserve worker bytes/object/path headroom before admission. Retain the 1 GiB envelope, 32-object/128 MiB response and existing phase/actor limits. A tiny native film does not qualify multi-GiB masters or a real episode. |
| [Sound](../../.roles/sound-designer.md) | Reuse the existing independent media checker. This adapter adds no translation, narration, performance or alignment and does not treat a worker receipt as listening or language review. |

The qualified SDK's native object gates are exclusive. Buffered control decoding
must relinquish its gates before file-provider admission reopens those same
objects under the still-live job claims. Likewise native publication/readback
deduplicates byte handles while preserving every logical result binding.

The existing-pool fixture preserves all original roots and operation references,
including on failure. Its first integration run found the control-gate transition
error before producer dispatch; recovery continues that same admitted job with
the original pinned worker/media tools. Qualification records distinguish the
repair driver from the original producer runtime. No cache initialization,
hydration, project-profile changes or scratch retirement occurs.
