# Native scene reference binding review

Producer-applied Rights and Provenance Steward; Platform and Audience checklists.
These findings are not independent agent execution or actual human approval.

Provenance: native selection resolution stays in the existing Rust authoring
engine. The inspector does not guess required inputs from filenames, arbitrary
JSON, reports, inventory membership or unused binding entries. It records exact
metadata hashes and native fingerprints. Selected input absence holds the
context even if symbolic validation passes. Selection-state labels remain
declarations, not consent or creative approval. No private source data enters
public fixtures or review text. Full private graphs and receipts remain assets.

Platform: the saved offline view labels required selected inputs separately from
inventory observations and shows its registry snapshot generation. It preserves
search, navigation, pagination, text-only rendering and network-denying policy.
The UI has no mutation or approval controls. Browser layout acceptance remains
open; script interaction tests do not substitute for it.

Remaining boundary: native scene resolution is a scoped structural/symbolic
check. Source-text/word-alignment contents, template-definition payloads, decoded
media, real rendered timing, whole-episode delivery and human decisions retain
their separate validators and authorities. Standalone partial-coverage findings
remain visible; a successful scene context never clears an incomplete episode
graph merely to make a strict check pass.

Validation: 134 Windows asset tests (130 unit, four integration), the shared
authoring crate tests, ten offline UI interaction tests and strict crate clippy
pass. Formatting, ROLES structure and whitespace checks pass. Full root,
Windows/Linux and FFmpeg checks run in the PR workflow. No browser layout
inspection or private production render is claimed.
