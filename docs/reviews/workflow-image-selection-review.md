# Retained image selection adapter

Author-applied Animation Director, Editor, and Rights and Provenance checklists;
not independent review, human creative approval or project adoption.

The owned-ref transaction now has an image-specific caller. It checks an exact
ImageCandidate packet/result and its original selected image input, verifies the
frozen record-to-leaf declaration, and accepts only record, selected-leaf and
owned-decision replacements. Original record paths must be individually
enumerated, so a byte-identical record alias outside that declaration cannot be
substituted. The qualified SDK re-resolves the entire proposed native catalogue
before any selection intent or CAS. New-path and stream-slot transactions refuse.

- Animation/Editor: logical ID, definition, authored controls (including any
  project story/cel fields), streams and metadata are unchanged. Status is
  cleared. No clock, cue, frame map, caption, neighbor or consumer is rewritten.
  Stable identity checks are not visual continuity approval. A producing project
  must still explicitly rebuild the affected controls/languages/consumers.
- Rights/Provenance: the project supplies a live authority implementation for
  exact decision bytes and old/new subjects. Serialized flags do not create it.
  Old status cannot silently approve replacement bytes; prior approvals remain
  exact historical records. The new decision is pinned and committed in the same
  proposal. Native retained verification reopens real ownership and bytes and
  holds its guard through selection and recovery. Staged acknowledgements alone
  refuse. No release permission, profile adoption or speech authority is added.
- Effects: metadata inspection performs no provider execution, payload read,
  native admission, proposal write or ref change. Apply only changes the explicit
  owned selection ref after detached semantic validation. It does not change
  branches, working files or active production profiles. The underlying
  transaction's conservative uncertainty/ABA rules remain unchanged.

Focused metadata tests cover unchanged historical approval and stable identity,
wrong subjects/decisions/leaves/aliases, carried status and extra changes. The
native fixture uses only an explicitly declared existing synthetic pool, one red
PPM and an existing synthetic green PNG, with a synthetic authority implementation.
It is not production authority, a corrected-film assembly, affected rebuild,
600-resource/large-master qualification, adoption or rollback acceptance.
