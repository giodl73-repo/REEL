# W3a film file bridge review

Author-applied checklists under [.roles](../../.roles/ROLE.md), not independent
review, creative approval or project adoption. This slice connects verified
native paths to the existing renderer trait; it runs no producer.

| Lens | Finding and disposition |
| --- | --- |
| [Rights/provenance](../../.roles/rights-provenance-steward.md) | A read-only source context is insufficient execution authority. Require live claims for the exact packet/source and preserve them through the file lifetime. No upload, selection or new voice work. |
| [Rights/provenance](../../.roles/rights-provenance-steward.md) | Identical payload bytes must not substitute logical records or programs. Require authored aliases, exact input pins and task-pinned auxiliary executable bytes. Keep runtime paths guarded; no PATH fallback. |
| [Editor](../../.roles/editor.md) / [Animation](../../.roles/animation-director.md) | Use the existing renderer's input interface. This adapter does not reinterpret styles, durations, cut clocks, cel IDs or approval subjects. |
| [Sound](../../.roles/sound-designer.md) | Verified input paths alone do not establish recording choice, cue timing, captions or mix correctness. Preserve source identity; retain those execution checks for the producer slice. |
| [Platform](../../.roles/platform-audience.md) | A small file bridge fixture cannot qualify an episode or delivery format. State input bounds separately from admission/output limits, and keep large film execution and adoption explicitly open. |

Ordinary Windows tests refuse missing claims, swapped byte-identical aliases,
changed program pins, changed task authority and reserved auxiliary paths before
payload reads. The optional existing-pool test checks one synthetic object and
guarded path access without rendering. CI checks default and film feature builds;
no CI pool initialization or private project processing is added.
