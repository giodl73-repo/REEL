# Explicit cel picture candidates

Producer-applied review using the Editor, Animation Director, Sound Designer
and Rights and Provenance Steward checklists. This is technical review of the
generic contract, with no human picture/listening acceptance or project adoption.

- Editor: the shared selector admits only existing effective pictures and the
  descriptor's explicit candidate bindings. Comments, stable IDs, exact holds,
  cue grouping, undo and draft locks retain their existing meanings. Unknown
  cel IDs remain invalid. Listing an alternative never inserts a cel.
- Animation Director: native substitution appends a picture revision rather
  than overwriting the previous selection. Synthetic bilingual compilation
  checks both languages and preserves the protected language. Picture style,
  continuity and actual rendered appearance require project review.
- Sound Designer: picture alternatives cannot name a cue take or alignment
  binding. Recording identity, cue clocks and sound decisions are unchanged.
- Rights and Provenance Steward: candidate names are bounded and locked by the
  raw project descriptor; bindings carry native asset identities. Missing or
  invalid identities fail. Media export verifies named cache objects within
  its existing total budget, refuses corrupt earlier tiers and writes independent
  working copies. Controls-only export performs no media lookup. No registry
  registration, lease, creative approval or publication authority is implied.

Coverage includes real CLI export on tiny synthetic caches, copy-budget and
corruption rejection, native candidate application and delivery compilation,
and DOM handlers for media/controls-only and scoped/unscoped editors. DOM tests
do not establish browser layout, image decoding, playback or rendering.

The deliberate remaining boundary is asset lifecycle admission: producers must
register primary dependencies and hold the appropriate draft lease before
execution. The next unit should qualify a private candidate through the shared
installed runtime and controlled rendering, then address new native cel IDs
without weakening old-session locks. No private project data appears here.
