# BERTICA v0.2.1 requirement matrix

| Requirement | Implementation | Acceptance evidence |
|---|---|---|
| Stable series/season/episode identity and order | `reel.series.v0.1`; strict unique IDs and contiguous declared order | Generated 5-season × 10-episode slate validates as exactly 50 episodes |
| Reference children without embedding | Path, work ID, SHA-256, accepted timing/review, platform, privacy, source, duration | Hash/state mismatch, duplicate, missing, and incompatible-child negative paths in validator |
| Titles, poems, dependencies, continuity state, risks, motifs | Episode metadata and approved dependency records | Poem continuation and poem/prose structure gates |
| Canonical coverage and omissions | `series-coverage` plus child-to-episode coverage equality | Continuous blocks 34–4419 with overlap/order/bounds checks |
| Distinct timing and runtime values | Raw orientation, narration, pause, scene, episode, and season values | Child/episode/season mismatch rejection |
| Independent Bertica/Herman findings | Reviewer-keyed findings and review queue | 50-episode fixture reports zero approval and 50 open reviews |
| Release safety | Timing, review, privacy, source, platform, speaker, continuity, and human approval gates | Release-ready state rejected when any gate remains open |
| Atomic episode composition | `episode-compose` staging + atomic publish | Poem threshold + prose + attributed end-card packet test |
| Child identity and pause preservation | Child hashes, offsets, protected-pause IDs in packet lineage | Packet test retains `poem-to-prose-pause` and original child hashes |
| Continuous episode captions | Deterministic SRT parsing, offsetting, and rendering | End card appears at 7.500–8.500 seconds after child captions |
| Production-authored bridges/cards | Typed production units with mandatory source kind | Non-production-authored units rejected |
| SRT cue import | `cue-import-srt`, mapping/global assignments, atomic derivative | Four poem + two prose cues round-trip byte-for-byte |
| Exact protected silence | Imported cue timing checked against protected pause duration | 1,500 ms poem-to-prose gap assertion |
| Cue validation | Millisecond parser, overlap/bounds/shot/speaker/source checks | CLI and library acceptance tests |
| Shared continuity | `reel.continuity.v0.1` with path/version/hash/entity references | Seven-entity registry validation and resolution |
| Scene overrides | Local entity overlays preserve age, observations, clothing, condition, confidence | Flattened scene-local fields survive v0.2 serialization |
| Privacy-safe provider package | Approved observations only; local reference paths never serialized | Forbidden Herrera photo blocks transfer and never appears in JSON |
| No scene schema change | Production constant remains `reel.manifest.v0.2` | CLI validation reports v0.2; crate/release version is 0.2.1 |
