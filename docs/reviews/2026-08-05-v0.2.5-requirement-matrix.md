# v0.2.5 render-lineage requirement matrix

| Learning | Implementation | Verification |
| --- | --- | --- |
| A separate doctor report can be misplaced or associated with the wrong render | Embed the successful `RenderEnvironmentReport` in every real artifact report | Real sanitized artifact contains the nested report and seven checks |
| Environment evidence needs a stable comparison key | SHA-256 fingerprint over ordered identity and capability fields | Unit test recomputes valid lineage and rejects altered identity |
| New artifacts must not silently omit the evidence | v0.2.5+ `animatic-check` requires `render_environment` | Real CLI negative test removes the object and is rejected |
| Dry runs must not imply executable verification | Dry-run artifacts record `render_environment: null` | Default CLI assertion |
| Old artifacts should retain their verification contract | Environment lineage is optional before tool version 0.2.5 | Semantic-version gate unit coverage |
| Legacy reproduction may run without smooth-only support | Lineage waives only `perspective` and cubic interpolation for explicit legacy artifacts | Unit fixture accepts those two omissions and rejects them for smooth lineage |
| Consumer schema stability | CLI 0.2.5; `reel.manifest.v0.2` and artifact schema v0.1 remain unchanged | Full regression suite and existing v0.2 fixtures |
