# Film image repair role review

Author-applied Animation Director, Editor, Sound Designer, Platform and Audience,
and Rights and Provenance lenses; no independent review or creative approval.

- Animation: correction/continuity/style instructions remain explicit. Only the
  reviewed drawing and explicitly selected original references enter the task.
  Output bytes and a PNG contract do not establish continuity or image quality.
- Editor: exact reviewed frame/attachment and C/story identities stay in the
  task. Scoped snapshots preserve historical subjects. No timing change or
  retargeting against a latest drawing occurs.
- Sound: recordings and clocks are not repair inputs by default. An image task
  cannot rewrite narration or move a semantic cue. Assembly remains separate.
- Platform: manual and proxy callers use existing packets/results. The declared
  graph's ES/EN consumers are both listed for shared drawings. Consumer impact
  is not evidence that either edition has been rebuilt.
- Rights/Provenance: private report text is visible in the exported prompt, and
  later egress requires its explicit provider call. Neither old approvals nor
  creative selection transfer. Byte/metadata checks do not authenticate original
  retained production provenance; native admission must bind that evidence.

The source leaves original jobs, requests, tasks, profiles and media untouched.
No storage engine, automatic publication, native claim release or selection
transaction is added. Remaining gates include original retained invocation
binding, approved candidate application, affected consumer/result rebinding,
protected rebuild, actual project acceptance and adoption/rollback.

Qualification includes the workflow regressions and five new refusal/impact/
manual-return tests. A separate explicit synthetic media walkthrough exercises
the review-copy-to-candidate path and is reused by the real-media regression.
It verifies blue-to-green pixels, preserved C/story/frame intervals, untouched
neighbor target and byte-identical D/M/E/mix WAVs. It is not real episode qualification.
