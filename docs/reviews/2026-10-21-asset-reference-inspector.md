# Asset reference inspector review

Producer-applied checklists: Rights and Provenance Steward; Platform and Audience.
No independent agent execution, actual human approval or browser visual acceptance
is asserted by this review.

Provenance: exact manifest/version locks are distinct from observed inventory
members and contextual Golden scopes. Existing authority evidence remains opaque
and cannot become a build dependency or approval by accidental hash discovery.
Only supported, declared document relationships are traversed. Unknown ancestry
keeps unknown size. First-tier corruption does not silently select another copy.
Reports never authorize deletion, global orphan classification or publication.
Public REEL contains only code, bounded documentation and synthetic fixtures;
private catalogues, inventories, graph exports and acceptance receipts remain
upstream cache/LFS assets.

Platform: the standalone view offers search, typed relationship filters, bounded
node pagination, details and clickable incoming/outgoing links. It shows findings
and scope limitations alongside inspection results. Inventory edges explicitly
say that membership does not establish a build dependency. Labels use literal
text. Embedded data escapes script delimiters; the content policy blocks network
access. No install, daemon or server is needed to view a saved report. The view
has no cache mutation controls. Browser layout inspection remains open.

Coverage: exported projection schemas are not advertised as complete native
semantic validators. Episode content, cues, score, motion, bindings, rights and
creative decisions still require their own validators/authorities. Direct
references are not presented as a complete transitive rebuild impact analysis.
Retained views are snapshots; later registry changes require new inspection.

Validation: 127 Windows Rust asset tests (123 unit, four integration) and nine
offline browser-script interaction tests pass, including the existing cache
manager tests. Strict crate clippy, formatting, ROLES structure and whitespace
checks pass. The scripts are tested with a DOM double; this does not substitute
for browser layout inspection. Full REEL checks also run in CI on Windows/Linux.
