# Native cel insertion review

Producer-applied Editor, Animation Director, Sound Designer and Rights and
Provenance Steward checklists. No human creative acceptance is represented.

- Editor: one explicit split inside an existing hold preserves full recording
  coverage. Callers author both native event fragments and fresh stable IDs.
  Old-session imports still reject unknown rows; insertion emits a new source
  for a fresh session. Old owner drafts remain separate immutable feedback.
- Animation Director: a fresh picture slot has one initial revision. Existing
  slots/revisions remain intact. Scoped and separate-language graphs protect
  other lanes; actual compilation covers both languages in both arrangements.
- Sound Designer: recording/cue identity and native sample clocks are fixed.
  New score, Sonic/VFX and trigger declarations are explicit authoring intent;
  no source-word measurement or sound decisions are inferred by insertion.
- Rights and Provenance Steward: the command reads explicit locked controls
  only, writes a new candidate, and grants no registry, version, consent or
  release authority. Unknown fields, collisions, stale locks and attempted
  approval reject. All public data/tests are synthetic.

The compiler fixture initially exposed stale graph timing. Insertion now holds
such a source before creating output. Explicit native identity application is
the separate normalization path; insertion does not repair unrelated events.

Scope is deliberately one existing hold in one scene node. Creating a recording
or cue, extending a timeline, browser authoring of insertion proposals, registry
admission/leases and private new-cel media/render qualification remain separate.
Existing source-reader/compiler and protected-lane tests complement the new
positive/negative insertion and actual CLI export tests.
