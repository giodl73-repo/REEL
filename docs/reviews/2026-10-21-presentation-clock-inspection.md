# Presentation clock inspection: producer review

Method: producer-applied Editor, Sound Designer, Rights/Provenance and
fixture/lifecycle/repository-size checklists. No independent or human approval.

Editor/sound: shared pure compilation preserves native line anchors and explicit
scene-versus-overlay clocks. Missing native performance coverage is a hold,
not an invitation to delete a cue. Existing unrelated source/native results and
historical creative selections stay intact.

Rights/privacy: output contains only counts, clock integers and hashes. No ASS,
private line text, voice credits or media enters public REEL. Compilation does
not prove font/layout quality, measured audio, rendered timing or consent.

Fixture/lifecycle: six new tests cover bilingual compile/hash/clocks/privacy,
per-language marker holds, identity/content/soundtrack rejection, exact descriptor
and corrupt first copy, duplicate fields/BOM, explicit prerequisites, snapshot
changes and compile/read budgets. Two chapter-clock regressions moved alongside
their shared function. A real private fixture produces a newly detected coverage
hold under the same renderer rules; retain it without rewriting source assets.
Browser interaction tests use a DOM double; visual acceptance remains open.

Validation: 159 asset tests,49 assembly tests,21 renderer regressions and strict
asset/assembly/renderer clippy pass locally. Full platform CI required before
integration. Private runtime, inputs, reports and validation belong in cache/LFS.
