# v0.2.13 requirement matrix

| Requirement | Evidence |
| --- | --- |
| Exact artifact binding | Target is a required existing positional input; kind/schema and computed SHA-256 are recorded |
| Reviewer finding fields | Strict reviewer key, selection/objection/resolution, private reason, timestamp, scope, advisory/final authority |
| Independent append-only records | Existing output refusal; no update/delete command; multiple records remain separate and hash-indexed |
| Explicit resolution | Final resolution requires selected option, two hash-verified independent non-resolution citations, same target/scope, and actual disagreement |
| No false authority claims | Authentication, signature, consent, and approval fields are required false; fabricated approval acceptance test fails atomically |
| Private reasons | Records retain reasons locally; queue reports only status, missing reviewers, counts, resolution, and gates |
| Series queue integration | Separate series-hash-bound index; missing, agreement, disagreement, resolved, and decision gates without series schema changes |
| Remaining release gates | Explicit resolution clears the decision gate only; existing `release_ready: false` remains release-blocked in acceptance |
| Acceptance | A→B, B→C disagreement; final resolution→B cites both; originals hash unchanged; overwrite/false approval rejected |
| Manifest stability | `reel.manifest.v0.2` and `reel.series.v0.1` unchanged; no migration |
