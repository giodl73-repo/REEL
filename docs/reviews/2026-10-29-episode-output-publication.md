# Checked composition output publication

Producer review using Editor, Sound Designer and Rights/Provenance checklists.
This is technical review, not independent or human creative approval.

Previously the protected parent action returned a general callback value. A
native episode could be checked and assembled without a sealed correspondence,
complete publication contract or reopened output resource set.

`ProtectedComposition::assemble` now requires the exact admitted conform pin,
cache-backed parent/scene controls and explicit primary/output providers. It
uses its own bound runtime and the existing native full-frame, PCM and timestamp
verification. It issues `RenderedComposition` only under current parent and child
ownership. The result cannot be deserialized or constructed by callers and
borrows the protected parent plan. All retained master/compact delivery outputs
and the exact receipt are rehashed before correspondence or publication.
The candidate also borrows its actual source guard: another independent worker
cannot publish that candidate even when it owns the very same plan. The fixture
creates this concurrent identical-plan peer and requires refusal before writes.

Explicit output subjects must match independently admitted asset byte pins.
Empty, duplicate, wrong-name and wrong-byte mappings refuse. Complete publication
reuses the scene publisher's preflight, byte/count budgets, capability checks,
stable operation keys and output/receipt/claim ordering. A failure can leave a
verified prefix; exact retries recover it without deleting local files. Current
parent/child ownership is checked before and after even a failed publication.

`PublishedComposition` binds the acknowledged set to its exact plan. Output
resource freeze/readback retains all native outputs, receipt and claim alongside
the original composition/evidence/runtime roles. Runtime manifest and child
declaration bodies must still match. A foreign plan, old input-only selection,
missing nodes or substituted interpretation refuses.

Editor/Sound: existing ordered-frame, exact PCM and timestamp checks remain in
the native builder. This does not confer approval on pacing, cuts or sound.
Rights/Provenance: claims remain unsigned correspondence, not execution
attestations or approval. Local cache acknowledgement is not public delivery or
independent retained custody. Original selections and approvals do not change.

## Verification and remaining acceptance

The generated cache-only episode fixture exercises actual source-checkout-offline
assembly, the sealed result, rejected mappings/budgets/capabilities, mutated
payload/receipt refusal before provider writes, interruption at the receipt,
exact-prefix retry, repeated publication and recovery through a reopened cache
publisher. It freezes and reopens output resources with the render directory
unavailable and asserts exact output/composition/runtime/control/evidence roles.
Publication does not change the source journal or remove local/source bytes.

Local all-target/all-feature locked Clippy passed. The final all-feature cached
episode fixture, including the independent identical-plan peer, passed in 189.78
seconds. The full v1/edit/v2/Git/cache lifecycle passed in 106.81 seconds. Earlier
cached fixtures passed in 236.55 and 525.67 seconds while the path was extended.
Episode planning regression passed all 13 tests; regular Tig input regression
passed 71, with 12 explicit external/media tests ignored by that normal command.
The two episode media fixtures above were invoked explicitly, not skipped.
The original-producer/new-checker fixture also passed in 353.93 seconds with its
independently pinned original executable. Library tests passed 205, with nine
explicit external/media tests ignored by that normal command. Hosted qualification
must be recorded for the exact PR head before merge.
The shared publication extraction also requires the normal scene publication
tests and full edit/version/cache fixture; no weakening of old contracts.

The six explicit current Tig media qualification commands now use the same
all-feature build as the main test suite, avoiding an unnecessary second current
binary build on Windows. Every test and assertion remains; the independently
admitted historical producer still builds from its original source/features.

Remaining: actual retained presentation eligibility, generation/text freshness,
native CLI/scheduler integration for parent production, complete retained child
closures and verified owner handoff before retirement. The parent resource set
still has no child primaries and reports incomplete claim coverage. All child
owners must remain. This low-level assembly API does not reserve disk or bound
scratch itself; production callers must use the existing bounded job runner.
No live cache operations or runtime bindings are changed by this implementation.

Retained-media migration must not rewrite an original receipt's plan hashes to
match a newly compiled job. Geometry, clock and output-pin checks alone do not
prove that a changed cel or cue was rendered. Preserve original correspondence
or establish an explicit checked equivalence of consumed native contracts and
independent input/output correspondence. A new technical check cannot impersonate
the original producer or transfer the original creative approval.
