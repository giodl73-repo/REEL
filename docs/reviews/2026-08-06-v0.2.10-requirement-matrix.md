# v0.2.10 requirement matrix

| Requirement | Evidence |
| --- | --- |
| Per-cue caption and badge boxes | `layout.json` emits declared pixel regions for all SRT cues and activates badge regions only for lineage events |
| Fonts, margins, safe intersections, occupancy | Report records sizes, four margins, renderer colors/background/outline/padding, frame containment, overlap, and maximum percentage |
| Representative visual evidence | First/middle/last cue midpoint PNGs plus deterministic horizontal contact sheet |
| Artifact binding | `animatic-check` runs first; report stores artifact, video, caption-lineage, and presentation hashes |
| No OCR or overclaim | Measurement scope explicitly excludes OCR, glyph bounds, translation, device, and human-legibility claims |
| Privacy | JSON has no paths, captions, or identities; docs mark burned frames private and receipts remain unchanged |
| Atomicity | Nonempty output refusal, staging publication, tampered-artifact rejection, and no rejected packet in real acceptance test |
| Manifest stability | `reel.manifest.v0.2` unchanged; no migration |
