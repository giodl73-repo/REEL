# Public documentation navigation review

The former README mixed the founding lab description, many feature-introduction
notes, a long command catalogue and current native/Tig features. Installation
still described the older CLI and WSL transport as though they covered every
workflow. The October tooling roadmap also treated episode execution mainly as
pending work despite the newer managed execution interfaces.

The new front door gives readers a capability map, a short executable planning
example and task links. Separate getting-started, architecture and use-case
guides explain authored controls, resolved assets, jobs, candidates, review and
delivery. The documentation map distinguishes current guidance, exact contracts,
proposals and historical evidence. A topic index covers all 190 other top-level
docs; existing detailed contract files remain in place. Repetitive feature notes
are removed from the README in favour of those linked references.

Installation maps actual Cargo features/targets and separates legacy WSL
transport, native programs, Windows runtime protection, print and optional older
Python adapters. The roadmap records open drafts #120/#128/#144 separately from
working managed episode execution. PRODUCT_PLAN is identified as founding
direction/milestone history. Public Tig's guide now links back to the common
architecture and installation paths.

Detailed entry guides also replace obsolete future-renderer/CLI-adoption wording
with links to current managed routes. Cel, note and underlay guides point to the
shared Rust host. Presentation qualification counts are explicitly historical,
and obsolete pending-CI notes are removed while preserving their fixture results.

## Maintainer-applied role checklists

These are walkthrough/checklist findings, not independent user testing, reviewer
approval, private-project qualification or creative selection.

- **Editor:** information order starts with the task and a runnable example;
  implementation details and introduction-version references are one level down.
- **Platform and Audience:** a newcomer can distinguish the hosted WASM graph
  inspector, explicit local authoring host, browser frame renderer and Tig
  catalogue. Windows-only protection and external dependencies are visible.
- **Rights and Provenance Steward:** source/runtime identity, private evidence,
  creative authority and provider-readback limits remain distinct. No example
  uploads media, changes cache policy or claims an index is remote custody proof.

## Walkthroughs and checks

1. New reader: README → quickstart; build, validate, plan and measured conform
   run successfully against the checked-in synthetic controls. Conform produces
   a 7,500 ms packet with manifest, captions and lineage, without media tools.
2. Tig producer: README → public integration → architecture/native compiler;
   exact IDs, definitions, captured views and runtime adoption stay explicit.
3. Cel/music editor: use-case table → matching editor → local host → native
   apply. A downloaded draft is not represented as a rendered or selected asset.
4. Print/music owner: native print/albums are separated from older Python and
   recognition/engraving workflows; their supported scope remains linked.
5. Delivery/storage operator: saved inventory association, provider observation,
   actual delivery, custody and explicit eviction application are distinguished.

Relative links across 195 top-level/entry-point documents resolve (487 checked).
Changed-document path casing and heading anchors pass separate checks. All ten
documented executable targets exist in Cargo metadata. The complete reference
index matches the actual top-level doc set. No code, schema, runtime, cache or
workflow configuration changes are part of this documentation pass.
