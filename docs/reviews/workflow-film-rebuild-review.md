# Candidate film rebuild review

Author-applied REEL Editor, Sound Designer, Animation Director and Rights and
Provenance checklists. This is not independent review or human approval.

- Editor: exact attachment IDs and old file subjects identify replacements.
  Scene timing, contract, neighbors and ordering remain unchanged. The scheduler
  requires all direct consuming languages and withholds stale downstream
  assemblies. Existing upstream closures refuse until their origins can be
  merged explicitly; repeated repairs are not claimed as fully supported.
- Sound Designer: selected recordings and bus settings are copied only from the
  same language's original job. Tests use differing English/Spanish contracts,
  recordings and durations. No alignment, breath, mix or caption regeneration is
  inferred from a still replacement. The actual media repair fixture checks
  original versus repaired audio, cue boundaries and neighboring frames.
- Animation Director: only explicit still sources change. Crop/motion/camera
  settings remain present, with geometry review required rather than assumed
  valid for a new image. Videos and ambiguous targets refuse.
- Rights/Provenance: create-only candidate outputs preserve original files.
  No network call, asset selection or authority comes from a control/result
  declaration. The planner reports missing native binding and false selection,
  approval-transfer and completed-render status. Raw scene-control validation
  and live native custody remain separate checks.

Remaining acceptance: protected control production and authenticated baseline
reopening, native source binding, affected-language dispatch and exact downstream
rebinding, real-project authority/profile adoption and full episode scale. The
existing synthetic render check does not establish bilingual production adoption.
