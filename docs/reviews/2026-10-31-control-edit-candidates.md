Scope: bounded Rust worker/CLI, synthetic file and managed-job/proposal fixtures,
and its contract. Existing capacity, publisher, journal and Git-proposal engines
remain unchanged. No production cache, selection, renderer or runtime binding is
modified by this implementation work.

The current native cel-editor rehearsal produces one changed alignment Object
whose stable ID maps to one existing Tig record. The missing seam is constructing
the unreviewed record and protecting both new Objects through proposal creation.
A bare file-publication receipt cannot establish that ownership. The worker
therefore emits candidates only; the existing managed runner owns retention.

subjects to remain historical and rights/authority metadata to survive. New
status is unreviewed and grants no execution or creative approval. Private
diagnostics and raw requests remain outside Git. Editor review requires stable
identity, preserved source/history and exact edit/control pins; native semantic
validation remains the editor/consumer's responsibility. Storage/Git review
requires independently reopened job output roots before proposing cached record
bytes, and no release of byte claims merely because a Git ref was created.

tests, strict Clippy and hosted qualification. These are producer findings, not
independent reviewers or human acceptance. Tooling owns actual authoring handoff

remain open. The worker is not a new cache, registration authority or model
