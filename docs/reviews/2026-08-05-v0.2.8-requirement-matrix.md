# v0.2.8 caption accessibility requirement matrix

| Requirement | Evidence |
| --- | --- |
| Catch unreadable timing before render | Minimum duration and maximum visible-character rate per cue |
| Catch dense layouts | Maximum line length and line count per cue |
| Reject malformed timelines | Strict UTF-8/SRT parsing, cue index, positive duration, and overlap checks |
| Keep policy adaptable | Four explicit CLI threshold overrides; defaults recorded in every report |
| Do not echo private dialogue | Report carries only hash, aggregates, cue indexes, rules, measurements, and limits |
| Work as a CI gate | Failed audit prints JSON and exits nonzero; hosted Windows/Linux coverage exercises a passing fixture |
| Avoid false rendered-caption claims | Documentation states that SRT analysis is not pixel OCR or device review |
| Preserve consumer schema | CLI v0.2.8; `reel.manifest.v0.2` unchanged and no migration |
