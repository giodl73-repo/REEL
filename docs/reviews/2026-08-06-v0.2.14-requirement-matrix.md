# v0.2.14 requirement matrix

| Requirement | Evidence |
| --- | --- |
| Actual geometry and safe area | Verified child width/height; deterministic 8% safe rectangle and bound checks per slate |
| Wrap/scale without clipping | Word wrapping, long-word splitting, one-pixel font descent, explicit 18–32 px platform-derived floor and line limits |
| Atomic infeasible failure | Layout is computed before staging/render; acceptance rejects 500-character labels with no MP4/artifact/receipt |
| Local artifact evidence | Policy, selected font, line breaks, timing, boxes, safe result, and per/maximum occupancy retained |
| Optional representative PNGs | `comparison-layout` atomically extracts full-resolution opening and every primary variant slate frame |
| Exact packet binding | Sibling receipt binds artifact; receipt and artifact bind video; packet binds all three and every PNG hash/length/timestamp |
| Tamper rejection | Acceptance independently modifies a PNG, video, and artifact; `comparison-layout-check` rejects each |
| Receipt privacy | Existing strict receipt contains no copy, presented label, screenshot, private instruction, or local path |
| Receipt verification scope | `comparison-receipt-check` remains limited to intentionally shareable lineage and delivery facts |
| Format stability | `reel.manifest.v0.2`, `reel.comparison.v0.1`, and `reel.comparison-receipt.v0.1` unchanged; no migration |
