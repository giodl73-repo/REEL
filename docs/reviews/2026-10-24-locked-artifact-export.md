# Locked artifact export review

Producer-applied editor and rights/provenance checklists; no independent or
human creative approval. This is working-copy transport, separate from current
selection, custody, residency, native rendering and publication.

The new commands bind an explicit version and package hash, map only named
registered roles, and require a bounded new working folder. Dry run writes
nothing; export revalidates rather than trusting an old plan. Unique sources
are verified before output creation and each destination is hashed during copy.
The completion receipt is written last. No global lock, archive recovery,
recursive reference traversal or cache mutation is introduced.

Windows: 290 asset-crate tests pass, including stale/missing locks, unknown
roles, copy admission, corrupt-first-tier refusal, explicit read roots,
case-insensitive duplicates, path traversal/device names, file/directory clashes,
preserved selections and independent working copies. Strict all-target scoped
Clippy, formatting and ROLES checks pass. A Unix-only regression additionally
checks a symlinked working parent.

A frozen private historical package reopens 51 explicitly mapped files under
a 64 MiB budget. All restored hashes match; the old frontend plays its media
through its matching earlier host. Both native language compilations pass.
The old browser draft correctly refuses against a different candidate descriptor
lock. Fresh export/download/apply against the restored native descriptor then
passes both language compilations. Both hosts expire normally. Project control
hashes remain unchanged, with no render or new cached media copy. Detailed
evidence stays in the producing project's cache/LFS, not this public repository.

No blocking finding in this scope. A plan is not a lease or future availability
guarantee. Interruption or I/O failure can leave a partial new directory without
a completion receipt; existing directories refuse and require explicit
reconciliation. Human picture/listening acceptance and final-render review
remain open. The commands are documented in [the contract](../artifact-export-v1.md).
