# v0.2.11 requirement matrix

| Requirement | Evidence |
| --- | --- |
| LUFS-I, LRA, true peak | FFmpeg EBU R128 diagnostics parsed into strict numeric fields |
| Clipping/near-clipping evidence | Sample peak, true peak, samples-at-maximum, threshold violations, and synthetic clipped rejection |
| Stream and duration facts | Codec, sample format/bit depth, rate, channels, duration, and optional 50-ms manifest comparison |
| Silence | Leading, trailing, and internal ranges with profile edge/internal thresholds and time-ranged violations |
| Stem margin | Both stems required together; independent hashes/facts and narration-minus-effects LU margin |
| Profiles | Audiobook, podcast, YouTube-audiobook, and private-review policies serialize all thresholds |
| Privacy/locality | Adapter-local FFmpeg/ffprobe only; strict JSON contains no path/name/text fields; acceptance asserts no path leakage |
| Artifact binding | Passing report schema, hash, profile, audio hash, and duration checked before render and by `animatic-check` |
| Analysis only | No normalize, repair, clone, synthesize, upload, selection, or approval operation |
| Acceptance | Synthetic −19-ish LUFS pass, clipped fail, stem margin, duration mismatch, overwrite refusal, bound render, tamper rejection |
| Manifest stability | `reel.manifest.v0.2` unchanged; no migration |
