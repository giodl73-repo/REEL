# W3a.2 native lifecycle review

Author-applied inspection under [REEL role rules](../../.roles/ROLE.md), not
independent review or production approval. Scope: exact native inputs, protected
manual work, retained results and guarded slot close. Fixtures are synthetic.

| Lens | Finding and disposition |
| --- | --- |
| [Rights/Provenance](../../.roles/rights-provenance-steward.md) | Matching bytes alone could replace a selected record/leaf. Bind canonical scopes, exact commit, explicit leaf/stream declarations and task identity; reject alternate aliases, stale takes and undeclared reads. |
| [Rights/Provenance](../../.roles/rights-provenance-steward.md) | A lost reply could duplicate publication or release waiting inputs. Preserve task/attempt, WorkRef, activation and checkpoints; record intent first, reconcile original work and retain claims through errors/waiting. |
| [Rights/Provenance](../../.roles/rights-provenance-steward.md) | A candidate receipt could be treated as durable completion. Require positive retained coverage and reopened bytes. Close requires the exact Retained journal and original acknowledgement before qualified handoff/clear. No deletion or scratch retirement follows. |
| [Editor](../../.roles/editor.md) | Storage work could change the active film or its exact approval subjects. Connect metadata inspection only; preserve original controls, clocks, identities and approval associations. Execute no producer and adopt no project profile. |
| [Platform/Audience](../../.roles/platform-audience.md) | Small native fixtures could imply episode-scale support. Report capabilities explicitly; retain supported budgets, preflight response/close path bounds before admission, and refuse unqualified large execution. Native input metadata/stream support is separate from large-job qualification. |

The original SDK source bytes remain unchanged. Build-output copies fix Rust
module layout without patching qualified source or adding an unlisted vendor
file; tests compare those compiled copies byte-for-byte. Additive asset helpers
provide typed contention, preserved-capacity lease reopening and held directory
identity guards. Existing transaction waits and producer SDK pins remain intact.

Retained tension: durable waiting work consumes one of the finite actors until
explicit retained-owner close. This adapter does not expire or delete abandoned
work. Actual film dispatch, large-resource lifecycle qualification, provider
accounts, expected-baseline selection and owned adoption remain later gates.
