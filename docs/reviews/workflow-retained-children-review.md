# Retained dependency admission

Author-applied Editor and Rights and Provenance checklists; not independent
review, creative approval, release authority or project adoption.

This extracts the generic retained-input contracts from the preserved workflow
prototype without its unrelated producer adapters. Portable bindings distinguish
logical task/result/selector identity from byte equality. Native frozen origins
carry exact operation witnesses; they remain data until live parent verification.
The child archives those witnesses with its own projection and acquires its own
positive claims before any manual wait or guarded production.

- Editor: the adapter does not edit cels, ordering, selected takes, semantic
  trigger clocks, captions, or consumer controls. It enables exact parent outputs
  as inputs to the existing producer. Declared large intermediates are metadata
  bounds, not complete-episode composition acceptance. Source v1/v2 declarations
  stay unchanged; cross-snapshot parent access requires an explicit binding version.
- Rights/Provenance: parent/child projects must match. A staged receipt, forged
  origin, matching payload bytes or serialized retained acknowledgement cannot
  create child admission. Actual retained ownership and complete native results
  reopen under current fences. Film tool parents additionally require the
  existing exact worker/request proof. Other tool producers refuse. No approval
  transfers to a replacement image or new consumer output.
- Lifecycle: retained owner/controller locks are shared per session, preventing
  recursive acquisition when parents share an owner. Byte gates drop before new
  index work; parent fences remain until child claims settle. Namespace guards
  preserve the exact controller roots. Generic admission refuses upstream tasks.
  Child waiting, cancellation and recovery do not release parent history or
  expire child claims. Explicit retained coverage/close is still required.
- Bounds: one enrolled reader/store, unchanged 1 GiB admission envelope,
  512 objects, 128 changed paths per phase and 16 actors. No implicit phase
  splitting, pool initialization, hydration, provider call, cleanup or capacity
  growth is added. Unsupported producer/pool combinations stop before effects.

Portable tests cover exact parent versions, changed attempts/projects, worker
selectors, same bytes with different origins and explicit streaming limits.
Native metadata tests cover admission bypass refusal, unchanged legacy identity
and native witness changes independent of logical parent identity.
