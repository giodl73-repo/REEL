# v0.2.12 requirement matrix

| Requirement | Evidence |
| --- | --- |
| Two or more variants, declared order | Strict 2..=26 child contract, unique IDs/receipts/videos, ordered embedded evidence |
| Opening/variant slates, chime, silence, replay | Deterministic H.264/AAC slate segments, optional local chime fit check/delay, protected trailing room, explicit replay slate |
| Descriptive and deterministic blind labels | Strict mutually exclusive modes; seed-derived A–Z permutation; raw seed/decode only local |
| One changed dimension | Supported dimension allowlist; changed dimension cannot be fixed and must have at least two distinct evidence signatures |
| Fixed-dimension enforcement | Duration/stream receipt facts and caption/motion/voice/mix/visual artifact hashes; missing evidence or mismatch rejects before output |
| Preserve child evidence | Every child receipt is validated, hash-recorded, and embedded in the local parent artifact |
| Parent artifact and path-free receipt | Local lineage/decode artifact plus strict shareable receipt and recipient-side video checker |
| No inferred approval | Artifact/receipt set `inclusion_order_is_approval: false`; no preference/approval field or inference |
| Atomicity | All children/fixed dimensions validate first; video/artifact/receipt stage and publish as a rollback group |
| Acceptance | Three six-second caption-only variants compose; altered-audio child fails; parent receipt verifies and leaks no path/ID/label/seed |
| Caption verifier bug fix | Numeric serialization tolerance is limited to 1e-9 for caption report floats; all hashes/policies/cues/events/violations remain exact |
| Manifest stability | `reel.manifest.v0.2` unchanged; no migration |
