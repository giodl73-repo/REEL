# Existing-film board projection review

Author-applied Editor, Sound Designer, Animation Director, Platform and Audience,
and Rights and Provenance checklists from `.roles`. This is not independent review
or approval to adopt a production profile.

- Editor/Animation: shared-event order, story/C identity and language-specific
  selected picture subjects project from the existing inspector. A new drawing
  changes the subject, not its unit identity. Simultaneous ambiguous picture cuts
  refuse. This adapter is one inspected scene slice, not a new conform or renderer.
- Sound: exact committed text, trigger words, sample rates, positions and selected
  takes are retained. Spanish source is unchanged by dirty working-tree text.
  Preview substitutions must match the exact take; language clocks remain separate.
- Rights/Provenance: every approval's exact subject and evidence artifact survive,
  including historical and multiple references. They do not approve a newer subject.
  Native custody, authority and adoption remain unverified. Export opens no media,
  calls no model, performs no hydration and creates only the explicit new output.
- Platform: configurable language order avoids imposing an English default.
  Inspector approval evidence is visible with subject/hash distinctions. Existing
  desktop/narrow and browser listening acceptance from parent #405 remain open.

Four new portable tests cover committed projection and CLI refusal/preservation.
The eight original inspection tests still exercise the same shared synthetic Git
fixture after its extraction into test support; no production API changed there.
The three existing Windows board tests also pass. Strict Clippy and formatting
pass locally. Hosted results must qualify the exact PR head before landing.

No actual show, approved recording, current selection, production profile or
native job was changed. Generic git-asset preview/launch integration and full
episode-scale acceptance remain separate requirements.
