# Caption and bounded-programme integration

This is a producer-applied technical checklist review, using the editor and
rights/provenance questions in `.roles/ROLE.md` and the lineage, portability and
approval boundaries in `.pitfall/PITFALL.md`. It is not an independent review or
creative approval. Local test logs remain outside source control.

## Selected behavior

Integrate native episode caption sidecars, resumable normalization in a closed
workspace, immutable programme parts, prefix composition, and optional persistent
chapter-title plates. Caption words and language come from pinned selected source
tracks; their placement follows the verified native episode sample clock. An
explicitly empty track can cover a caption-free title section.

Keep current main's protected input/control/output providers, explicit media-tool
bindings, source-clock browser behavior, optional chapter numbers, declared
lossless presentation encodings, color interpretation checks and repeat-only
frame-clock limits. Retained source formats continue to follow current main's
fresh source verification, rather than the older branch's narrower codec list.
Strict native inputs still require stereo PCM24.

The standalone preparation and preassembled-master routes cannot consume protected
native providers through a local-file fallback. Their workspace custody and job
checks remain separate. A regression exercises refusal before local media reads
or output creation. Normalized output facts report square pixels after the
declared square-pixel transformation.

## Branch disposition

- The workspace-window recovery and retained-sample-cache fixes already have
  current equivalents. Retain current implementations rather than restoring
  obsolete recovery interfaces.
- Caption and programme branches contain useful behavior and are reconciled with
  current interfaces. Preserve both current and older media regression coverage.
- The square-pixel output-facts correction is included with the preparation path
  that exercises it; the rest of its inherited legacy pipeline is not a separate
  replacement for current native production.
- Old project handoff notes and historical private production reports remain in
  their retained source history; they are not current qualification evidence.

## Qualification boundary

Required checks include formatting, all-target/all-feature Clippy and tests,
workspace-crate tests, actual FFmpeg picture/PCM comparisons, caption timing and
stale-input rejection. Prefix composition has a normal current-producer fixture
and a separately invoked authentic historical-producer fixture whose binary hash
is checked before use. Hosted required checks must pass on the actual PR head.

A source merge does not install a shared executable, replace a managed producer,
change project bindings, render an episode, approve media or grant publication.
Project adoption requires its own pinned runtime and actual output qualification.
