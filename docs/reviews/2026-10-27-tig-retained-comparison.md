## Implemented boundary and evidence

The managed CLI now has an explicit `compare-retained` operation. Original
producer admission and current validation-tool bindings are separate. Native
receipt/plan/output agreement is independently checked before exact decoded
comparison. The existing media parity implementation now uses its provider's
program selection for probes, frame hashes and PCM decoding; explicit refusal
precedes payload lookup. The comparison path discards subprocess stderr rather
than accumulating unbounded default-volume temporary diagnostics.

The extended managed CLI fixture passed in 223.81 seconds with source Git,
records and definitions physically offline and PATH empty during comparison.
It checks equality, existing-report refusal, insufficient budget, wrong context,
wrong producer, output mismatch, missing output, wrong receipt and corrupt bytes.
A valid different-content baseline produces a private mismatch report and failure
exit. Metadata checkpoints and source remain unchanged, and owned compiler/copy
scratch is removed on both success and handled failures. The first local attempt
correctly refused the existing fixture's 1 GiB workspace admission on the nearly
full C volume; running the same unmodified fixture with TEMP/TMP on D passed.
No capacity limits were relaxed and no user assets were removed.

The actual retained Melena scene also passed through the supported CLI, without
another render. Seven native media outputs plus the receipt were independently
checked, using 163,084,352 bytes of temporary copies. The 1280x720, 24 fps master
matched its independently pinned original selected baseline across all 2,268
frames and 4,166,568 native 44.1 kHz stereo samples: picture planes, displayed RGB,
color metadata, PCM and clocks all agree despite different container objects.
The bounded private report is 2,780 bytes and remains on the admitted cache volume;
raw source/output/tool pins and report paths are not published in Git. The check
does not change the candidate's unapproved status or main's selected record.

Local final checks: 58 ordinary native-input tests pass (nine external tests
remain explicitly ignored by that invocation); the ordinary explicit-program
refusal test and strict external content/color/clock/length parity test pass.
Locked all-target/all-feature Clippy with warnings denied, no-default-feature
library isolation, formatting and whitespace checks pass. The actual final-tool
comparison left no owned compiler/copy scratch directories. Exact-head hosted
Linux, Windows and FFmpeg qualification is still required before squash merge.
