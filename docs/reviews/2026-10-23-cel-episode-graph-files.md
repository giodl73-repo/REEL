# Separate native language graph review

Base: main `d19ca51`. Producer-applied Editor, Animation Director and
Rights/Provenance checklists. This records technical findings, not independent
review, creative approval or production adoption.

| Finding | Correction and evidence |
| --- | --- |
| Real episode controls select separate native graphs for each language | Optional project-v3 `protected_graphs` explicitly routes every other lane's graph and pointer. The selected core files retain the edited lane. Complete language coverage, native pointer locks, scene identity and exact event/picture-slot domains validate before output. Graphs are never merged. |
| Slot names have meaning inside their graph | Separate-domain fixtures intentionally reuse a slot label across languages; editing the target still preserves the protected file. Combined-graph shared-slot protection remains unchanged. |
| Protected controls must survive actual application | All graph/pointer/index/alignment bytes are captured and locked. Separate graph/pointer buffers pass native typed parsing before JSON normalization. Stale hashes, duplicate language keys, missing domains, wrong pointers, aliases and escapes refuse. Candidates reopen through the complete intake contract. |
| Private native intake needs a useful entry point without media hydration | `inspect` emits a bounded create-new private report containing a locked identity edit template and cue clocks. Standard output contains counts/scope flags only. It reads declared controls and resolves no media, starts no server and grants no approval. Overwrite refusal is tested. |
| Synthetic success alone misses real source layout differences | An isolated registered private metadata snapshot has two languages, eight cues each and thirteen selected cels each. Six identity/reorder/removal candidates preserve the other lane's exact graph/pointer/index/alignment bytes. Both languages compile for every candidate: twelve native delivery-control compiler passes. All original descriptor/control locks still match afterward. |

Public fixtures test independent native compilation of both language graph files.
Windows validation: 313 asset/assembly Rust tests plus four root compiler
integration tests (317 total), strict scoped Clippy, formatting, ROLES and diff
checks. All 32 asset/editor JavaScript tests pass. Unix-only path coverage remains
part of normal CI.

Private fixture construction read only explicitly named registered JSON controls
and checked their size/hash, about 146 KB total. Full requests, paths, identities,
hashes and compiler reports remain private outside the public repository.
No production media, images or credits are included here. No producer worktree,
selected version, runtime pin or cache object was modified. No rendering, server,
daemon, hydration, new cache root or eviction occurred.

Browser layout, audio/video acceptance, rendered output validation and runtime
adoption remain open. Compilation writes native delivery controls; it does not
establish media custody, selected-version authority or creative acceptance.
New-asset insertion, shared-slot forks, multiple scene nodes and simultaneous
linked language edits remain outside the bounded editor contract.
