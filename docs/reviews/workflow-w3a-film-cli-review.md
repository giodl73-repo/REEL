# Owned film CLI review

Author-applied [.roles](../../.roles/ROLE.md) checklists, not independent review
or creative approval. Scope is explicit owned CLI dispatch over the existing
capacity ledger and qualified film APIs.

| Lens | Finding and disposition |
| --- | --- |
| [Rights/provenance](../../.roles/rights-provenance-steward.md) | Require externally pinned private requests/tickets, original accepted protection and exact producer/media tools. Returned control JSON cannot allocate a replacement lease or adopt a different workspace. No new voices, model calls, selection or uploads. |
| [Editor](../../.roles/editor.md) | Run the exact existing film task and retain its producer evidence. Resume reconciles the original operation and checks original media; it does not repeat rendering or change cut/cue identity. |
| [Platform](../../.roles/platform-audience.md) | Reserve declared process workspace plus control overhead before production, hold the existing lease during work, and keep it on errors or completion. Native close does not imply scratch/capacity retirement. Existing production-scale limits remain explicit. |

Workspace ownership checks bind parent, root and working-directory filesystem
identities, internal immutable intent/ticket bytes, volume and the exact capacity
ledger entry. The root admits only known protocol entries. Input media remain
in the existing native store; preparation creates only owned workflow controls.

Qualification uses the previously completed synthetic task's existing pool and
index with a separately named, explicit attempt after its original slot closed.
The new attempt preserves its request, binary, ticket, capacity and scratch; no
project profile or production asset is changed.
