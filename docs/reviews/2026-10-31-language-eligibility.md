# Eligibility belongs to the consumed language

The real retained-control rehearsal exposed a production-scope defect: a new
unreviewed Spanish alignment correctly blocked Spanish compilation, but also
blocked the unchanged English lane. Source and byte retention were intact; the
native preflight and delivery compiler both resolved production eligibility for
every language before using the requested one.

The assembly resolver now offers an explicit single-language entry with named
season/episode/scene binding scopes. Its existing full-scene entry preserves its
all-language behavior. Shared presentation, requested-language cues/cels,
alignment, soundtrack and other consumed inputs keep their strict checks. Native
Tig compilation, delivery compilation and selected-language scene build/verify
use the scoped entry. All declared Tig references still undergo type/identity
admission; no inactive object admits an output as a primary.

Producer-applied editing and provenance review requires unchanged language
contracts, explicit draft refusal on consumed inputs and no approval transfer.
Git/adoption review keeps the fix independent of any creative selection: the
rehearsal proposal remains isolated, and its result owner remains protected.
These are producer findings, not independent review or human approval.

The new synthetic regression covers both a draft other-language take and a
draft other-language alignment, with absent candidate bytes. It compares exact
current-language production/contract/job bytes and semantic/input fingerprints,
then requires the consuming language and shared draft cel to refuse before
output creation. The first run reproduced the downstream compiler's remaining
all-language guard; applying the scope at both boundaries addresses the cause.

The requested-language API does not qualify another language, malformed source,
unknown types, source ownership, media generation or creative approval. The
existing whole-scene resolver remains available for an explicit all-language
validation operation. Actual native consumer replay, focused scope/assembly
tests, strict Clippy and hosted qualification remain required for adoption.

Local verification passes: 35 language-scope tests (seven explicitly ignored
runtime/operator tests), 51 assembly tests and strict locked all-target,
all-feature Clippy. The synthetic regression's initial failure was corrected at
the downstream compiler boundary, with production eligibility retained for all
actually consumed inputs.

Further front-door checking found `resolve-language` still calling the full-scene
entry. Its CLI now uses the same scoped resolver; the regression invokes both
language commands and explicit whole-scene validation, preserving refusal for
the consumed draft and the all-language command.

Hosted Windows qualification exposed a separate fixture error: a current
compiler captured the context handed to the older producer. The producer
correctly refused the foreign interpretation. Cross-version tests must capture
historical contexts with the historical compiler. The fixture separates
same-compiler/different-runtime source-currency checks from genuinely older
compiler revalidation. The latter requires strict historical claim replay to
refuse, and explicit retained-contract revalidation to verify old bytes without
claiming current production. No production guard is relaxed and no existing
source-currency case is removed.

The optimized candidate independently passes the actual retained-scene
revalidation: seven outputs and 163,084,352 bytes, exact decoded equality, no
materialization, no historical claim replay or approval transfer. This does not
override the hosted failure; the corrected fixture and full qualification remain
required before the candidate can be installed.

Corrected local qualification passes: the explicit source-pinned compatibility
fixture runs both branches successfully (540.22 seconds), and strict locked
all-target/all-feature Clippy passes. The front-door language regression also
passes. Hosted checks must qualify the corrected head; the earlier failed head
remains unqualified.
