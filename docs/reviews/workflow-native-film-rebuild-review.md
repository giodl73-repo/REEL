# Native film rebuild review

Author-applied Editor, Sound Designer, Animation Director and Rights/Provenance
checklists; not independent review, creative approval or release authority.

- Editor: original baseline packets and Git declarations must agree. Each new
  language job gets only its own control origin and the shared image origin.
  Stale downstream assemblies remain withheld by the portable planner.
- Sound Designer: the payload check recomputes the exact still replacement from
  the same original job. Changed recording, cue contract or duration refuses;
  the metadata scheduler alone never proves those payloads preserved sound.
- Animation Director: explicit attachment targeting and expected old references
  govern the transform. Preserved camera/crop/motion can still need image review.
  This changes no renderer or motion grammar.
- Rights/Provenance: frozen origins and staged acknowledgements remain metadata
  until live upstream admission. Child-owned claims govern actual reads; native
  selection and approval remain separate. The new CLI request field is omitted
  for old requests, preserving their serialized request/ticket identity.

The native catalogue tests use real Git and deliberately non-live staged
synthetic origin metadata. They qualify binding/refusal and unchanged index
state, not payload custody or an end-to-end bilingual protected render. Actual
retained child rendering is qualified separately in the retained-child adapter;
the complete automatic repair application remains open.
