# Selected presentation source checks: producer review

Method: producer-applied Rights/Provenance, Lyrics/Vocal Adaptation and Editor
checklists. No independent reviewer, agent or principal approval is claimed.
Scope: shared scene projection helpers, rendering CLI reuse and opt-in asset
inspector source checks, synthetic failures, UI relationship description/docs.

Rights/provenance: source hash and declared scope do not prove ownership or
permission. Preserve unverified authority/delivery semantics; report original
manuscript/audio content verification and inferred approval false. No external
service/destination access. All consumer evidence stays in its private cache.

Lyrics/adaptation: preserve exact wording, stanza structure, language and
separate translation state. Native source-line ownership checks reject unrelated
performances. V2 display hashes use the existing native verifier. Draft text stays
review-held after technical success. No automatic correction or transcription.

Editor: move the existing rendering CLI's invocation/scope extraction to shared
native helpers, rather than duplicating scene grammar. Full cue/performance
coverage, alignment timing, template-definition contents and rendered acceptance
remain separate; selected source-text consistency is the bounded claim.

Six new asset tests cover bilingual success/privacy, wording/stanza/scope/
authority/language/document/text-state failures, unrelated native performance,
first-tier corruption/wrong schemas, descriptor byte mismatch/V2 display hashes,
explicit opt-in, budgets and changing source metadata. Existing asset suites,
shared authoring suites and renderer template tests validate compatibility.
Browser tests use a DOM double; independent visual acceptance remains open.
