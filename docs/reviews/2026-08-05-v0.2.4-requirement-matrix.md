# v0.2.4 render-environment requirement matrix

| Learning | Implementation | Verification |
| --- | --- | --- |
| CI-only shell probes do not help consumers | `render-doctor` exposes the same gate in text and JSON | Real WSL command returns `reel.render-environment.v0.1` with every check green |
| Incompatible FFmpeg builds otherwise fail after setup work | Real `animatic-render` calls the shared preflight before rendering | Existing real sanitized render passes through the new gate |
| Substring matching can report false capabilities | Filter and encoder listings are matched by complete whitespace-delimited tokens | Unit fixture omits `subtitles` and reports exactly that missing check |
| Smooth motion needs more than a named filter | The doctor checks both `perspective` and its cubic interpolation option | Complete and incomplete parser fixtures |
| Windows and Linux can inspect different installations | The report records `wsl` or `native` transport and both executable version lines | Local Windows invocation verifies the actual WSL adapter path; hosted Linux CI consumes the command |
| Legacy reproduction should remain available | Explicit legacy renders waive only the smooth-only perspective checks | Existing legacy command-shape and real-render acceptance tests remain green |
| Consumer schema stability | CLI 0.2.4; `reel.manifest.v0.2` remains unchanged | Full default regression suite and production fixture tests |
