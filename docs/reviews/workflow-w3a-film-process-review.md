# W3a contained film process review

Author-applied [.roles](../../.roles/ROLE.md) checklists, not independent review
or creative approval. This slice adds a contained process port over existing
film rendering. Workflow dispatch and retained completion remain open.

| Lens | Finding and disposition |
| --- | --- |
| [Editor](../../.roles/editor.md) | Reuse existing scene plans, clocks and media checks. Recovery checks original rendered bytes instead of producing another cut. Synthetic acceptance explicitly checks three frames and 4,800 content samples. |
| [Animation](../../.roles/animation-director.md) | Delegate picture behavior to the existing renderer. Child output tables bind actual bytes and the receipt; the parent rejects mismatches. No new style or renderer-readiness claim. |
| [Sound](../../.roles/sound-designer.md) | Use the existing independent picture/PCM checker. File hashes and process success alone do not qualify content, captions, mix or language selection. |
| [Rights/provenance](../../.roles/rights-provenance-steward.md) | Pin task, native source paths, renderer and media executables. Keep failed scratch and original intent; never replace an uncertain launch. No upload, selection, voice creation or retained-owner acknowledgement is granted. |
| [Platform](../../.roles/platform-audience.md) | Replace whole-output buffers with guarded streaming files. Permit explicitly bounded five-hour declarations while retaining independent admission limits. A small render and 128 MiB-plus streaming fixture do not qualify multi-GiB masters or episode delivery. |

The owned-workflow renderer API preserves failed staging; existing standalone
render APIs retain their existing behavior. Parent/child integration uses only
owned synthetic files and pinned installed tools. It does not qualify the full
native-source-to-retained-result workflow, real project adoption or rollback.
