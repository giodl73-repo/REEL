# v0.2.2 smooth-motion role review

## Scope

The review covers REEL's synthetic long-still fixture and renderer contracts.
It does not review or reproduce private BERTICA media.

## Findings

| Role | Verdict | Evidence | Boundary |
|---|---|---|---|
| Animation Director | Pass | Fractional cubic perspective sampling advances pans, pushes, and pulls continuously; 20/25-second acceptance renders pass the cadence gate. | BERTICA still owns the human-visible approval of its five private scenes. |
| Editor | Pass | Ease-in/out is deterministic, holds remain exact, and measured duration stays within one frame of the conformed timeline. | Motion repair does not authorize timing or edit changes. |
| Platform and Audience | Pass | 720p and 1080p remain CFR H.264 with existing caption/disclosure treatment. | 4K smooth rendering is intentionally gated by the memory bound. |
| Sound Designer | Pass | The filter graph changes video motion only; existing silent and audio/A-B paths remain distinct and synchronized. | Voice choice and mix approval stay with BERTICA. |
| CI Gate Auditor | Pass | Rust tests cover defaults, legacy compatibility, bounds, overwrite safety, and lineage; Linux runs real FFmpeg cadence acceptance and Windows exercises the same CLI construction. | Hosted Windows does not replace the local Windows-to-WSL production proof. |
| Repo Maintainer | Pass | The change is confined to CLI v0.2.2 and the still-animatic adapter; `reel.manifest.v0.2` is unchanged. | Future backends should not silently weaken the published metric. |
| Public Surface Scrubber | Pass | Fixture text/grid and generated proof are synthetic; no BERTICA path, manuscript, photo, voice, or private render is committed. | Generated MP4 proofs remain CI/local artifacts, not repository binaries. |

## Decision

Panel pass for a v0.2.2 review candidate. Smooth motion becomes the new default,
legacy reproduction remains explicit, and private-scene approval remains open.
