# Complete reference index

Use [the documentation map](README.md) for a short learning path. This index
covers every top-level Markdown document in `docs/`, grouped by topic rather
than release chronology. A version in a filename normally identifies a feature
introduction; the linked contract and actual runtime determine support.

Plans/checkpoints are listed separately. Reviews and handoffs remain in their
own [review](reviews/) and [handoff](handoff/) directories. Additional entry
points: [installation](setup/install.md), [manifest templates](../manifests/README.md),
[WASM source](../browser/assembly/README.md), [roles](../.roles/ROLE.md),
[principles/pitfalls](../.pitfall/PITFALL.md), [source provenance](../vendor/README.md).
