# Pulse 3: complete package and cross-platform control custody

The complete package at 330c21a passes all 20 local browser checks, including
36 native/WASM responses, seven original production-CLI controls, live WASM memory
limits, admitted node/reference/byte controls, request exports and source/legal
routes. All 1,352 Git source files and notices are retained. The package is below
5 MB including inventory after compact lossless source-pin JSON and removal of
the optional WASM debugging name section. No source, notice or contract behavior
is omitted; the original failed budget attempts remain in private QA records.

The first hosted Pages run failed while starting a copied native executable:
shutil.copyfile had not retained its Unix execute permission. Preserve that raw
failure. Use copy2 for these owned temporary runtime copies, assert executability
on Unix, and rerun the actual controls instead of relaxing the requirement.
Native runtime copies are removed after control hashes/results are retained;
the source/legal qualification artifact does not distribute extra native binaries
with a different dependency-notice closure. Published runtime remains WASM only.

Exact Git source is read in a checked single-process blob batch, without checkout
or archive substitutions. This reduces repeated process startup for the complete
source while retaining exact byte checks. Standalone/native production workflows
are separate: full Linux/Windows/FFmpeg CI, source replay, hosted candidate,
default deployment and fresh live verification remain required delivery gates.
