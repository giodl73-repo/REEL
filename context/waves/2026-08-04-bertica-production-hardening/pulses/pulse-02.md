# Pulse 02: Asset-backed animatic adapter

## Outcome

Implemented deterministic still-image animatic rendering through the external
FFmpeg adapter with captions, disclosure, motion, transitions, and provenance.

## Evidence

- `animatic-render` CLI command and dry-run mode.
- Input hashes for manifest, every visual, audio, and captions.
- Output hash, FFmpeg version, dimensions, frame rate, duration, and exact
  command arguments in the artifact report.
