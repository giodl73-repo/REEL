# REEL personas and lenses

REEL uses `.roles/` for binding repository-local review checklists. This folder
holds optional authored critical voices and production lenses; a persona never
represents actual human approval.

The initial portable lenses are story, edit, animation/cinematography, sound,
and platform/audience. Actual principal findings belong in manifest
`review.principal_findings` with a decision reference and remain separately
attributable.
